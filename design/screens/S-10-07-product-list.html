Layout

  • 375 — as the app: back, title (category flow: title + chevron opening S-10-08), sort, filter; subcategory chips scroll on row 2; one column of full-width cards with a tall image; the search pill floats above the tab bar.
  • 768 — floating glass bar; search moves into the bar; 2-column grid.
  • 1440 — title / category selector, search, sort (popover) and filter (side sheet S-10-10) in one row; chips beneath; 4-column grid (3 at 1200 with the menu expanded).
  • Flows: category (title is a selector), application (plain title + chips), brand (plain title, no chips).
  • Next page: one shimmer card appended. Empty and error are one centred line in the list area; there is no retry control.

Components used

  • Navigation shell · Top header (glass) with back · Category selector · Search input · IconButton glass (sort, filter with dot)
  • Chip as subcategory tabs
  • Product card (image carousel dots, rating pill, save, brand tag, SKU, title, Reference Price)
  • Skeleton cards · Empty line · Toast (danger, next-page failure)

Motion

  • Skeleton → content — --skel-*, --shimmer-*, --reveal-*; new page — --stagger-*
  • Chip change — --tabs-* (list scrolls to top; filters and sort reset)
  • Save — --icon-swap-*; card press — --press-*; filter dot — --badge-pop-*
  • Category switcher and sort — --panel-* (popover from 768); Filters — page slide under 768, --panel-* side sheet from 768

Accessibility

  • h1 is the title; in the category flow it holds a button named "Category: Sanitaryware, change".
  • Subcategory chips are a tablist with the selected state exposed. Sort and filter buttons are labelled; the filter button says "Filters, 3 applied" when the dot shows.
  • Products are a list; each card is one link named by its title, with brand, SKU, rating and price in reading order; save is separately focusable with a pressed state.
  • Loading sets aria-busy; empty / error text is a polite status.

Decisions to confirm

  • Category, subcategory, search, sort and filters stay in page state, not in the URL (product-owner answer Q-01).
  • In-list search does not send the active sort or filters (as the app) — typing after filtering drops the filters. Open question in F-10.
  • Filter dot and "n applied" are web additions so an active filter is visible; the app shows no indicator.
