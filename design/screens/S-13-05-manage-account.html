Layout

  • 375 — mirrors the app: floating glass bar (Back, centred title, pencil), cover, avatar over its lower edge with the verified tick, name, @username, category, optional switch tile, then section header (uppercase title, icon right) + rounded card of rows (label left, value and chevron right; Bio, addresses and Current Location stack the value under the label), Profile Visibility card, Delivery Locations, MORE.
  • 768 — the same single column at a comfortable form width beside the rail; every edit opens as a side sheet.
  • 1440 — two-pane settings: a sticky left column (photos, name, switch tile, section list with anchors) and the section cards on the right inside a 1120 content width. Edits open in a side sheet; photo picker and menus as popovers.
  • Roles: Homeowner (Personal Information only), Professional (+ Professional Overview, Work Preferences, Availability), Brand (Business Information / Overview / Work Preferences, Open to New Resellers), Reseller (business rows, two inline switches, no Delivery Locations).
  • States: default · empty (rows read Add / Select, Skills shows only its label, default cover and avatar art, delivery card has only Add Delivery Location) · loading (2-row delivery skeleton) · saving (switch tile shows a spinner) · deleting (row's trash becomes a spinner) · error (toast; switch reverts).
  • Subscription & billing is not shown anywhere (Q-21).

Components used

  • Top header · IconButton glass (Back, pencil) / plain (trash)
  • Avatar + verified badge · Switch · Tag (skills)
  • Section header (.section-head) · Settings row (.srow) inside a card
  • Skeleton · Spinner · Toast (danger)
  • Section list (desktop anchors) — plain links in a card

Motion

  • Back and rows that push a screen — --page-slide-* (mobile), --panel-* crossfade from 768
  • Rows that open a sheet — --panel-*; delete dialog — --modal-*
  • Switch — --duration-fast thumb slide; row / button press — --press-*
  • Section cards enter with --stagger-*; delivery skeleton — --shimmer-*; toast — --toast-*

Accessibility

  • h1 "Manage Account"; every section title is an h2; each card is a list and each row a button or link named by its label and value.
  • Cover and avatar are buttons labelled "Change cover photo" / "Change profile photo"; the pencil is "Update profile or cover photo".
  • Switches use role="switch" with a visible label; the saving and deleting spinners are status text.
  • Delete Account is marked by its label as well as the danger colour.
  • Toasts are announced in a polite live region; focus returns to the row after its sheet closes. Trash buttons are named with the location ("Delete Home").
