Layout

  • 375 — full screen, as the app's pushed screen: back, title, subtitle; search pill; the selected-location chip (when set); then results, "No results found" or the empty block.
  • 768 / 1440 — nested panel: it slides in over the Filters side sheet at the same position and Back returns to Filters.
  • Picking a result returns to Filters with the location shown under the "Location" row.

Components used

  • Side sheet (nested) · IconButton plain (back) · Search input (with clear)
  • Removable chip (selected location) · Result row (pin + description)
  • Skeleton rows · Empty state · Toast (danger)

Motion

  • Enter / leave — page slide under 768, --panel-* from 768
  • Results — --skel-*, --shimmer-*, --reveal-*
  • Row press — --press-*; toast — --toast-*

Accessibility

  • h1 "Location". The search field controls a listbox; each result is an option named by its description.
  • The chip's remove button is labelled "Remove {location}".
  • "Searching" and "No results found" are announced politely.
