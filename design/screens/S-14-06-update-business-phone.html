Layout

  • 375 — glass bottom sheet, three steps in one sheet. 1 Enter number: title, subtitle, country selector + number in one pill, inline error, helper, "SEND OTP" + "CANCEL". 2 Verify: title, subtitle, 4 code boxes, "sent to" line, "VERIFY" + resend. 3 Success: title, subtitle, success badge, message, "CLOSE".
  • 768 / 1440 — side sheet from the right over Manage Account; same three steps, actions pinned to the bottom.
  • Step 1 states: default (current number, SEND OTP disabled because unchanged), valid, invalid, same-number (defensive toast), sending, send-error. Step 2: verify, verify-filled, verifying, verify-error (boxes cleared), resend (countdown finished). Step 3: success.

Components used

  • Bottom sheet / side sheet
  • IconButton glass (close)
  • Text field with country Select (opens S-02-02 Country code)
  • One-time-code input (4 boxes, as S-02-03)
  • Button filled L (SEND OTP / VERIFY / CLOSE — loading, disabled) · Button translucent L (CANCEL / RESEND CODE)
  • Toast danger

Motion

  • Open / close — --panel-*
  • Step change — --tab-panel-*
  • Countdown digits — --text-swap-*
  • Success icon — --check-path-*
  • Button press — --press-*; error toast — --toast-*

Accessibility

  • Dialog named by its title; focus moves into the sheet, is trapped, and returns to the Manage Account row that opened it; Esc or the scrim closes without saving.
  • While saving the primary button is disabled and announces its busy label; toasts are announced through a polite live region.
  • Number input: digits only, max 10, inputmode="numeric"; the inline error is tied to it and announced.
  • Code boxes are a labelled group with one-time-code autofill; on a failed verify they clear and focus returns to the first box.
  • The countdown is not announced every second; "You can resend the code now" is announced once.

Decisions to confirm

  • Sign-out on success (Q-17, answered): verifying the OTP updates the number on the server and ends the session, so "CLOSE" (and closing the sheet) lands on Sign in (S-02-01). The success copy says nothing about being signed out — recommend adding a line; none added here because the app has none.
  • The verify-failure message comes from the server; "Invalid OTP. Please try again." is sample text.
  • Country flag: the app draws a circular flag image; the mockup shows the ISO code in a circle until a flag asset set is chosen.
  • Glyph: the app uses CheckmarkBadge04 for the success badge, which is not in ICONS.md — CheckmarkCircle01 is used instead.
