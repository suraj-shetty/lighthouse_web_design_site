Cancel Order

Are you sure you want to cancel this order? This action cannot be undone.

Layout

  • Centred dialog at every width over the Active Order screen: title, one paragraph, two equal buttons ("No", "Cancel Order").
  • Tapping outside or Esc closes it without cancelling.
  • There is no loading or error state inside the dialog: confirming closes it and shows the blocking loader (S-11-05); a failure returns to S-11-03 with an error toast.

Components used

  • Modal / Dialog (destructive confirm)
  • Button filled M ("No") · Button destructive M ("Cancel Order")

Motion

  • Open / close — --modal-*
  • Button press — --press-*

Accessibility

  • alertdialog named by the title and described by the body; focus is trapped; initial focus on "No".
  • Focus returns to the "Cancel" header action on close.
  • The destructive action differs by colour and by label.

Decisions to confirm

  • Dismiss on outside tap follows the GetX default; the spec marks it unverified.
  • On success the list opens on the "Cancelled" filter with the toast "Cancelled / Your order has been cancelled." (S-11-01, state cancelled).
