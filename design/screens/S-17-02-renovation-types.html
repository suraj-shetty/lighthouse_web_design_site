Layout

  • Not linked into navigation (Q-22): the Projects tab is hidden in the app, so no menu item, tab or other screen links here. The shell is shown with Home active only to frame the page.
  • 375 — mirrors the app: back arrow + title, intro paragraph, vertical list of type cards: 16:9 image, title + arrow, description, divider, starting price (left) and duration with clock (right). No tab bar (pushed screen).
  • 768 — 2-column card grid. 1440 — 3-column grid, one row.
  • The title is the category title passed in ("Renovation"). The same three types show whatever category opened the screen.
  • Loading and image failure show the flat placeholder block. No data loading, empty or error state.

Components used

  • Top header (back) · Style card (image card, list) · divider

Motion

  • Card press — --press-*; list entrance — --stagger-*
  • Push / back — --page-slide-* under 768, --panel-* crossfade from 768

Accessibility

  • Each card is one link named by its title; price and duration are text; the clock and arrow are decorative.
  • "Renovation" is the h1; card titles are h2; back is labelled "Back".
