Reseller shell

Reseller tab page

The selected reseller destination renders here. Switching back to the normal account replaces this shell with the main shell.

Destinations

  • DashboardReseller dashboard · active
  • OrdersOrder list · reseller-orders links open here
  • AnalyticsReseller analytics
  • NotificationsDot while there are unread items
  • Switch to normal accountAlways shown · returns to the main shell

Layout

  • 375 — as the app: floating glass pill with four icon-only tabs (Dashboard, Orders, Analytics, Notifications) and a circular glass "switch account" button to its right, always shown.
  • 768 — floating glass rail with the four reseller destinations and the switch control.
  • 1440 — the same menu expanded to a sidebar: labels and a clear "Switch to normal account" control.
  • States: default; loading — owned by the tab pages (skeleton in the content area); the switch button stays. Empty and error belong to the tab pages.
  • No role variants: the shell is only reachable by resellers.

Components used

  • Nav bar (mobile bottom tabs: glass, active pill, unread dot)
  • Sidebar / rail (from 768)
  • IconButton glass (switch account)
  • Skeleton

Motion

  • Tab change — --tabs-*, --tab-panel-*; unread dot — --badge-pop-*.
  • Switch to the normal account — crossfade --panel-* (700 ms fade in the app).

Accessibility

  • Destinations are links with text labels and aria-current; the switch button is labelled "Switch to normal account"; the mode change is announced after switching.
  • The spec asks for the landmark name "Reseller"; the shared shell currently names it "Primary" — to align at build.
