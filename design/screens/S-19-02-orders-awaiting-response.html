Layout

  • 375 — mirrors the app: full screen without the reseller tab bar; back arrow + title; one bordered container of order rows with hairlines. Row: 72 thumbnail, order number + status, product, brand chip + price, SKU, quantity; New rows end with "Reject" / "Submit Quote".
  • 768 / 1440 — the same container becomes a data list: thumbnail, details, and the actions (or a chevron on tappable rows) in a right-hand column, so rows stay short and scannable. Width is capped at 960.
  • Shows orders with status New, Won or Rejected, newest first. Won and Rejected rows open Order details (S-19-03); New rows are not tappable.
  • The next page of 20 loads near the end of the list with a spinner under it. A refresh button replaces pull-to-refresh from 768.

Components used

  • Top header (back) · Order row (list layout) · Status pill · Tag (brand)
  • Button translucent S (Reject) · Button filled S (Submit Quote)
  • Skeleton (4 rows) · Spinner (next page) · Empty state

Motion

  • Push / back — --page-slide-* under 768, --panel-* crossfade from 768
  • Skeleton to rows — --skel-*, --shimmer-*; appended rows — --stagger-*
  • Row and button press — --press-*

Accessibility

  • The title is the h1; back is labelled "Back".
  • Tappable rows are one link named "Order {number}, {product}, {status}"; New rows expose two buttons named with the order number.
  • The pagination spinner has a status role ("Loading more orders"); new rows are appended without moving focus.

Decisions to confirm

  • The app shows the status as plain text; the pill used on the Orders tab is used here for consistency.
  • Error has no retry control in the app, and a failed next-page load is silent.
  • From 1200 the spec allows a side pane for details; this design opens S-19-03 as its own page from this list.
