Layout

  • 375 — as the app: back + title, search pill under it, 2-column grid of image tiles (175:128) with a one-line name.
  • 768 — floating glass bar with the search inline; 4-column grid.
  • 1440 — 6-column grid inside the content max-width.
  • Opened from a brand's Shop tab the same screen lists that brand's applications and filters locally.

Components used

  • Navigation shell · Top header (glass) with back · Search input (with clear)
  • Style card (image + label tile)
  • Skeleton tiles · Empty line · Toast (danger)

Motion

  • Entrance — --stagger-*; skeleton → content — --skel-*, --shimmer-*, --reveal-*
  • Tile press — --press-*; tile opens S-10-04 (--panel-*) or pushes S-10-07
  • Back — page transition

Accessibility

  • h1 "Application"; search labelled "Search applications".
  • Tiles are buttons named by the application; images have empty alt because the name is the visible label.
  • Empty text and the result count are polite status messages.

Decisions to confirm

  • Title is "Application" (singular) as in the app.
  • A failed search silently shows "No matching applications found" (as the app); an initial load failure shows a toast, then "No applications found". No retry control exists.
  • Application names and images are sample data.
