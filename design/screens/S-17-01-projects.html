Layout

  • Not linked into navigation (Q-22): the Projects tab is hidden in the app, so no menu item, tab or other screen links here. The shell is shown with Home active only to frame the page.
  • 375 — mirrors the app: page title, two-line intro, 2-column grid of category cards (image with a status chip top-right, title, 2-line subtitle), floating tab bar.
  • 768 — 3-column grid beside the glass menu. 1440 — all four cards in one row.
  • Only "Renovation" is available. The other three are dimmed, show "Coming Soon" and do nothing.
  • Loading shows a flat placeholder block per image; an image that fails shows the same block with an image glyph. There is no data loading, empty or error state: the list is part of the app.

Components used

  • Nav bar / Sidebar · Top header
  • Style card (image card, grid) · Status pill ("Available", "Coming Soon")

Motion

  • Card press — --press-*; grid entrance — --stagger-*
  • Push to Renovation types — --page-slide-* under 768, --panel-* crossfade from 768

Accessibility

  • "Projects" is the h1; each card title is an h2.
  • The available card is one link; unavailable cards are not focusable and expose "Coming Soon" as text, not by dimming alone.
  • Image alt text equals the category title.
