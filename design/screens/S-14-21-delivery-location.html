Layout

  • 375 — tall glass bottom sheet: drag handle, title, subtitle, "Delivery Address *" with the search field and "Use current location", then "SEARCH RESULTS" (while typing) or the "SELECTED ADDRESS" card, then "ADDRESS DETAILS": Label *, Flat / House No., Floor, Landmark, and "SAVE".
  • 768 / 1440 — side sheet from the right over Manage Account; Flat / House No. and Floor share a row; "SAVE" pinned to the bottom.
  • Add: default everything empty · searching · results · no-results · locating "Fetching current location..." · location-denied · selected ready to save · address-missing · label-missing · saving · server-error. Edit: edit ("Edit Delivery Location", card and four fields pre-filled).
  • While a query is typed the selected-address card is hidden; picking a result clears the search.

Components used

  • Bottom sheet / side sheet
  • IconButton glass (close)
  • Search input
  • Button translucent M, icon-leading (Use current location, with busy)
  • Place tile (selected card with remove IconButton; result row)
  • Text field ×4 with leading icon (default, error, disabled)
  • Skeleton
  • Button filled L (SAVE, with loading)
  • Toast danger · Toast success

Motion

  • Open / close — --panel-*
  • Button press — --press-*
  • Error toast — --toast-*
  • Suggestions — --skel-* / --shimmer-*, then --reveal-*; selected address — --reveal-*
  • Success toast — --toast-*

Accessibility

  • Dialog named by its title; focus moves into the sheet, is trapped, and returns to the Manage Account row that opened it; Esc or the scrim closes without saving.
  • While saving the primary button is disabled and announces its busy label; toasts are announced through a polite live region.
  • Required fields are marked with an asterisk and required; the Label error is tied to its input and announced.
  • Browser location replaces the native permission flow: the button is busy while the position is read (8 s timeout), and a denied or unavailable position is a toast.

Decisions to confirm

  • Not shown to Resellers (no DELIVERY LOCATIONS section for that role).
  • Toast titles follow the app: "Address", "Label", "Location", "Saved". Location toasts by cause: "Please enable location services", "Location permission denied" (drawn), "Location permission is permanently denied. Enable it from settings.", "Unable to fetch current position"; reverse-geocode failure is "Error" / "Unable to get current location". On web "enable it from settings" should point at the browser's site permissions — copy to confirm.
  • The Label error is also shown inline on web (the app only toasts).
  • Glyphs not in ICONS.md and their stand-ins: LocationUser04 → Navigation03, Home01 → Home09, Stairs01 → Layers01, MapsLocation01 → Maps.
  • The four detail fields have no max length or format validation. Save does not send zone (Q-119). Deleting a location is S-13-10, opened from Manage Account.
