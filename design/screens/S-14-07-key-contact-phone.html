Layout

  • 375 — glass bottom sheet over the scrim: drag handle, title, subtitle, country selector + number in one pill, inline error under it, "UPDATE" above "CANCEL".
  • 768 / 1440 — side sheet from the right over Manage Account (440 wide, no drag handle); same order, actions pinned to the bottom.
  • default: saved number (last 10 digits) and country pre-filled; "UPDATE" stays disabled until the number is valid and changed. valid, invalid, saving, server-error follow.

Components used

  • Bottom sheet / side sheet
  • IconButton glass (close)
  • Text field with country Select (opens S-02-02 Country code)
  • Button filled L (UPDATE — disabled, loading) · Button translucent L (CANCEL)
  • Toast danger

Motion

  • Open / close — --panel-*
  • Button press — --press-*
  • Error toast — --toast-*

Accessibility

  • Dialog named by its title; focus moves into the sheet, is trapped, and returns to the Manage Account row that opened it; Esc or the scrim closes without saving.
  • While saving the primary button is disabled and announces its busy label; toasts are announced through a polite live region.
  • Number input: digits only, max 10, valid when it matches ^\d{10,11}$; the inline error is tied to it and announced.
  • The country button names the current country and dial code.

Decisions to confirm

  • No OTP step: the number is saved directly.
  • Saving sends the whole keyContactPerson object (name, designation, phone, email), because the backend replaces it.
  • Country flag: the app draws a circular flag image; the mockup shows the ISO code in a circle until a flag asset set is chosen.
  • State server-error shows the sheet as it stays after a failed request, with the "Error" toast (server message, else "Network error occurred" / "Something went wrong. Please try again later."). No retry control, as the app.
