Sharing

Layout

  • Every width — full-screen scrim with one centred spinner. No card, no text, no buttons, as in the app.
  • Blocks all input and cannot be dismissed. Create: closes once upload URLs are fetched and the app returns to Home, where the upload banner takes over. Edit: stays until the PATCH finishes or fails.
  • The composer also carries an in-button loading state (S-09-04 / S-09-08 "loading") — the same blocking behaviour for wide screens.
  • This dialog is the loading state; empty and error do not apply (an error closes it and raises a toast on the form).

Components used

  • Modal scrim · Spinner

Motion

  • Open / close — --modal-*
  • Spinner — continuous linear rotation; under reduced motion it stays still and the status text carries the meaning

Accessibility

  • The form is aria-busy; a polite live region announces "Sharing" because the dialog has no visible text.
  • Focus is trapped while shown and returns to the primary button on failure. Esc does nothing.

Decisions to confirm

  • Mockup only: tapping the scrim continues to Home so the flow can be clicked through; the product has no such action.
  • During an edit this covers compression and upload with no progress indication (as in the app).
