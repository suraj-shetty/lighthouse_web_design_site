Layout

  • 375: glass bottom sheet: centred drag handle, title, two equal compact cards (email, Call), then a full-width Location row (icon, title, address, chevron) when the profile has a primary base city.
  • 768 / 1440: popover anchored to the Contact button with the same content (380 wide).
  • States: default, loading (Call requested: spinner, tap disabled), empty (email "—" not tappable, Location row omitted), error (sheet stays open, toast).

Components used

  • Bottom sheet / popover
  • Select card, compact (email, Call) · Select card row (Location)
  • Spinner · Toast (danger)

Motion

  • Open / close: --panel-*; card press: --press-*; toast: --toast-*

Accessibility

  • Dialog labelled by "Contact". Cards are named "Email {address}", "Call {name}", "Open location in maps".
  • With no email the card is exposed as disabled; Call announces busy while the call intent is requested.
  • Error toasts use a polite live region: "Call failed" with the server message, "No number to dial was returned", or "Could not open the dialer".

Decisions to confirm

  • Masked calls on desktop (Q-28): Call creates a call intent and opens a tel: link to a masked number that is never shown. A desktop browser with no dialer ends in "Could not open the dialer"; the behaviour there is still undecided.
  • Location subtitle joins the display name and the full address ("{display}, {full}").
  • Chevron uses ArrowRight01 (Flutter uses a Material chevron, Q-34).
  • Popover rather than a side sheet from 768: the content is three targets and reads better next to its trigger.
