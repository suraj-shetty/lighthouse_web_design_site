Layout

  • 375 — glass bottom sheet sized to content: drag handle; title; subtitle; two rows (icon + label) separated by a hairline.
  • 768 / 1440 — popover menu anchored to the More actions button of the rail / sidebar.
  • Shown only to resellers. One state; no loading, empty or error state.

Components used

  • Bottom sheet / popover menu
  • Menu row (leading icon + label)

Motion

  • Open / close — --panel-*; row press — --press-*.
  • "New Post" closes the menu and pushes the create flow — --page-slide-*; "Switch to Reseller Account" crossfades to the reseller shell — --panel-*.

Accessibility

  • Named "More Actions"; the rows are menu items. Focus is trapped and returns to the More actions button; Esc, scrim and drag down close.

Decisions to confirm
