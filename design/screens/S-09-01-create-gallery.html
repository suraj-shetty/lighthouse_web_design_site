Layout

  • Web adaptation (Q-08, Instagram approach) — the device-gallery browser becomes a drop zone / file picker. The picker lists supported photo and video types only; the browser compresses before upload (Q-09).
  • 375 — glass header (close · title · NEXT). Nothing added: drop zone with "Select from device". After a pick: preview pager (40% of the height, n/total badge) → 3-column grid whose first cell is the add tile → floating Posts / Projects pill above the tab bar.
  • 768 — same order in one centred column; the grid gains columns.
  • 1440 — two columns: preview pager + type switch on the left (sticky), added-media grid on the right.
  • Roles: Projects tab only for professionals; brands and resellers see Posts alone; homeowners have no entry.
  • States: default, selected, drag-over, loading (reading / compressing files), empty (every picked file was filtered out, e.g. clips under 3 s), the two limit toasts, and add-mode (opened from an edit carousel — NEXT returns to the form).

Components used

  • Top header · IconButton glass (close) · Button filled S (NEXT, disabled until a valid selection)
  • File drop zone (.drop) · Empty-state tile
  • Image gallery: preview pager + image count badge · selectable grid tile with order number and video duration
  • Pill switch (Posts / Projects) · Skeleton · Toast

Motion

  • Type switch — --tabs-*; tile select and order badge — --select-check-*
  • Preview page change — --tab-panel-*; play / pause glyph — --icon-swap-*
  • Skeleton — --skel-* / --shimmer-*; new tiles — --stagger-*
  • Push to the composer — --page-slide-* (desktop --panel-*); toasts — --toast-*

Accessibility

  • Focus order: close → NEXT → preview → add tile → grid → type switch. The page heading is the title.
  • The drop zone action is a real button that opens the file picker; drag and drop is an enhancement, never the only way.
  • Each tile is a toggle button named with media type, duration and "selected, position n". The selection count is announced in a polite live region.
  • Disabled NEXT is described ("Select at least one photo or video to continue"). Type switch is a two-option tab list.
  • Mockup: the page badge and order numbers are static; the title and NEXT target follow the type switch.

Decisions to confirm

  • Drop-zone copy is new (not in the app): "Drag photos and videos here", "Drop to add", "Select from device", "Up to 10 photos or videos. Videos up to 90 seconds."
  • No library filter, albums or camera on web, so S-09-02 and S-09-03 have no entry point here.
  • Clips under 3 s are dropped silently as in the app; "No photos found" is shown when nothing usable remains.
  • Message says "less than 90 seconds" while exactly 90 s is accepted (kept verbatim).
