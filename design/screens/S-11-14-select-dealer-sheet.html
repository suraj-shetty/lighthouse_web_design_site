Layout

  • 375 — content-height glass bottom sheet: handle, title, subtitle, scrolling dealer cards (name + "Open Now", city, address, checkbox), pinned "SEND ORDER REQUEST".
  • 768 / 1440 — side sheet from the right, 440 wide, same stack; the footer stays pinned. Dealer cards stay in one column.
  • States: default none selected · selected two selected · empty "No dealers available for this product.", no CTA · error toast "Dealer / Please select at least one dealer".
  • Multi-select with no maximum. The last card shows the fallbacks "Seller", "City not available", "Address not available".

Components used

  • Bottom sheet / side sheet · IconButton glass (close)
  • Select card with Checkbox (default / selected) · Status pill "Open Now"
  • Button filled L · Toast danger · Empty line

Motion

  • Open / close — --panel-* (bottom sheet under 768, side sheet from 768)
  • Button press — --press-*; toast — --toast-*
  • Card select — --select-check-*; continue to S-11-15 — --panel-*

Accessibility

  • Dialog named by the title; dealers are a group of checkboxes whose names include name, "Open Now", city and address.
  • Selection shows a filled checkbox and a darker border, not colour alone.
  • The toast is a polite live region; focus returns to SELECT DEALER on close.

Decisions to confirm

  • "Open Now" is a fixed string in the app, not data (F-11-Q9); kept as is.
  • The toast appears at the top under 768 and bottom-right from 768 (the app shows this one at the bottom).
  • Selection is cleared whenever the sheet opens or closes.
