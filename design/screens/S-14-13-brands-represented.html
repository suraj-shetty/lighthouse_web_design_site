Layout

  • 375 — glass bottom sheet over the scrim: drag handle, title, subtitle, scrolling multi-select list of brands, "Save".
  • 768 / 1440 — side sheet from the right over Manage Account (440 wide, no drag handle); same order, actions pinned to the bottom.
  • default all brands, saved ones ticked · loading 4 skeleton rows · empty "No brands available" · error load failed: toast, then the empty text · saving · server-error save failed.
  • Reseller only. Brand names are sample data (label = profile full name, else full name, else username).

Components used

  • Bottom sheet / side sheet
  • IconButton glass (close)
  • Checkbox option rows
  • Skeleton
  • Button filled L (Save, with loading)
  • Toast danger

Motion

  • Open / close — --panel-*
  • Button press — --press-*
  • Error toast — --toast-*
  • Option toggle — --select-check-*
  • Skeleton to content — --skel-*, --shimmer-*, --reveal-*

Accessibility

  • Dialog named by its title; focus moves into the sheet, is trapped, and returns to the Manage Account row that opened it; Esc or the scrim closes without saving.
  • While saving the primary button is disabled and announces its busy label; toasts are announced through a polite live region.
  • Brands are a checkbox group labelled "Brands Represented"; loading and the empty text are announced as status.

Decisions to confirm

  • The list is unbounded with no search or paging in the app. A filter field would be an addition, so none is drawn — recommend one if the brand list is long.
  • Manage Account row reads "Add" for zero and "N Added" otherwise.
  • State server-error shows the sheet as it stays after a failed request, with the "Error" toast (server message, else "Network error occurred" / "Something went wrong. Please try again later."). No retry control, as the app.
