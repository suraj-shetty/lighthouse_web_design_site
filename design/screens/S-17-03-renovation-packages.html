Layout

  • Not linked into navigation (Q-22): the Projects tab is hidden in the app, so no menu item, tab or other screen links here. The shell is shown with Home active only to frame the page.
  • 375 — mirrors the app: back arrow, type title with the breadcrumb line "Build/Renovation" under it, intro, three stacked package cards, "BOOK SITE VISIT" pinned above the bottom edge.
  • 768 — package cards in 2 columns; the button sits right-aligned in the sticky bar.
  • 1440 — three cards side by side for comparison, equal height, "VIEW DETAILS" aligned along the bottom.
  • States are the three renovation types: "default" is Bathroom, then Kitchen and Full Home. The middle package of each carries the "Most Popular" banner.
  • No loading, empty or error state: there is no network call and no image on this screen.

Components used

  • Top header (back, two lines) · Metric card (package) · Banner ("Most Popular") · Tag (size chip)
  • Checklist · Button translucent L (VIEW DETAILS) · Sticky CTA bar + Button filled L (BOOK SITE VISIT)

  • Button press only — --press-* (both buttons do nothing in the app)
  • List entrance — --stagger-*; back — --page-slide-*

Accessibility

  • Each package is a region headed by its name (h2); "INCLUDES" is an h3; inclusions are a list.
  • "Most Popular" is text plus a star, not colour alone. Each "VIEW DETAILS" button names its package.
  • The breadcrumb is plain text, as in the app (not navigable).
