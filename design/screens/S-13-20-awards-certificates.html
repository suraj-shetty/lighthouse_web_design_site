Layout

  • 375 — back + title bar; intro card (title, description, "Add" pill) above the list card of certificates (name, issue date, chevron, hairlines).
  • 768 — the same column at form width (720 max).
  • 1440 — two columns: the list on the left, the intro card with "Add" sticky on the right. The form (S-13-21) opens as a side sheet.
  • read-only (from "View All" on About): only the list card; rows open the view-only sheet; back returns to About.
  • error: the toast raised by a failed add / update / remove; the list is unchanged.

Components used

  • Top header with back IconButton
  • Card · Button filled S ("Add")
  • Tap-to-open list row (settings row)
  • Empty state · Toast (danger)

Motion

  • Page enter — --page-slide-*; blocks rise with --stagger-*.
  • Row / button press — --press-*; sheet — --panel-*.
  • List updates after add / update / remove — --stagger-*.

Accessibility

  • One H1 "Awards & Certificates"; the intro title is an H2.
  • Each row is a button named "<name>, issued <date>"; "Add" is named "Add certification".
  • Empty text is real text; the toast is announced politely.

Decisions to confirm

  • No loading state: the list is seeded from the profile already in memory (no fetch on this screen), as the app.
  • Title is left-aligned beside the back button (kit pushed-screen pattern); the app centres it.
  • Fallbacks: missing name → "Untitled Certification"; missing date → "N/A" (last row shows it).
  • Web path for this screen is undefined (Q-01: follow the app flow).
  • The "Manage Account right pane" layout in the spec depends on S-13-05; here it is a pushed page.
