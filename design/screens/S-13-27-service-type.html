Layout

  • 375 — glass bottom sheet (up to 90% height): handle, title and subtitle, content, full-width button pinned above the safe area.
  • 768 / 1440 — side sheet from the right over Manage Account, same content, button in the sheet footer.
  • Scrollable list of rows: name on the left, tick box on the right, hairline between rows.
  • States: default saved services ticked · loading saving, rows disabled, button spinner · error toast, sheet stays open.

Components used

  • Bottom sheet / side sheet · IconButton glass (close)
  • Checkbox option row
  • Button filled L, with loading · Toast (danger)

Motion

  • Open / close — --panel-* (slides up under 768, slides in from the right from 768).
  • Tick — --select-check-*; press — --press-*; toast — --toast-*.

Accessibility

  • Dialog named by the sheet title; focus moves into the sheet, is trapped, and returns to the row it was opened from; Esc and the scrim close it.
  • Checkbox group named by the title; each row is one checkbox with its label.
  • While saving, rows are disabled and the button announces "Saving".

Decisions to confirm

  • Options come from the API per role; the names here are sample data.
  • The options load before the sheet opens, behind the blocking loader (S-13-09) — there is no skeleton in the sheet.
  • No empty state: when the role has no service types the row on Manage Account is hidden and this sheet cannot be reached.
  • Button label is "Submit" here while sibling sheets say "SAVE" / "Save" (verbatim from the app).
