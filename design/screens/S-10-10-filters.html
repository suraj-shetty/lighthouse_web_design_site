Layout

  • 375 — full screen, as the app's pushed screen: header (filter icon, title, subtitle, round close), scrolling sections with hairlines, CLEAR ALL then APPLY pinned at the bottom.
  • 768 / 1440 — side sheet from the right over the product list; same section order; the two buttons stay pinned.
  • Order: Location → Price Range (slider + min "-" max fields) → Color → Finish → Availability → Delivery Timeline → Rating → "More Filters • n Options" card.
  • A group with no options shows only its title (Availability on dev). "More Filters" lists only groups that have options and hides when none has any.

Components used

  • Side sheet · IconButton glass (close) · Tap row (Location, with "Clear")
  • Price range slider (two thumbs) · Text field ×2 (₹ prefix)
  • Colour swatch selector · Filter chip (single-select; Rating with star)
  • Accordion card (More Filters) · Radio (Yes / No)
  • Button glass L (CLEAR ALL) · Button filled L (APPLY) · Spinner overlay · Toast (danger)

Motion

  • Open / close — page slide under 768, --panel-* from 768
  • Chip, swatch and radio select — --select-check-*; More Filters expand — --panel-*
  • Button press — --press-*; toast — --toast-*

Accessibility

  • Dialog named "Filters"; each section is a fieldset with a legend; chip groups and swatches are radio groups.
  • Slider thumbs are labelled "Minimum price" / "Maximum price" with the value announced in rupees; the two fields carry the same labels.
  • Swatches are named by their hex value because the API returns hex only — a colour name is needed (content gap).
  • "More Filters" is a disclosure. The loading overlay sets aria-busy. Focus order ends on CLEAR ALL, then APPLY.

Decisions to confirm

  • Option values are the dev backend response of 2026-11-12, shown raw: 6 colours, 18 finishes, 5 delivery timelines ("under 60 mins", "1-2 weeks", "1-3 days", "custom", "same day"), ratings 1–5, Installation Available Yes / No. Availability, Warranty Available, Certification Available and Country of Origin were empty on dev, so Availability shows its title only and More Filters counts 1 option.
  • Price bounds on dev are 0 – 10,00,000 ("0" – "10L"); before the options load the app default is 0 – 1Cr (loading and error states).
  • Swatch colours use the nearest palette tokens because mockups may not contain raw hex; the real swatches use the API hex values.
  • Every group is single-select and a selected chip cannot be un-selected except through CLEAR ALL (as the app). Close keeps the changed selections in memory without applying.
  • Delivery timeline values are shown exactly as the API sends them (lower case).
