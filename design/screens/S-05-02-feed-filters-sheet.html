Filters

Select filter options to apply

Layout

  • 375 — glass bottom sheet (up to 90% height): handle, header with close, two panes (categories left, options right), RESET above APPLY.
  • 768 / 1440 — side sheet from the right with the same header, panes and footer.
  • One parent category at a time; "All" and specific options are mutually exclusive.

Components used

  • Bottom sheet / side sheet
  • IconButton glass (close)
  • Two-pane list: category tabs + checkbox option rows
  • Button stroke L (RESET) · Button filled L (APPLY / APPLY (n))
  • Skeleton · Toast (error)

Motion

  • Open / close — --panel-*
  • Category change — --tabs-*; option check — --select-check-*
  • Button press — --press-*

Accessibility

  • Dialog named "Filters"; focus trapped and returned to the filter button; Esc closes without applying.
  • Categories are a vertical tablist; options are checkboxes with visible labels.
  • APPLY announces the count when options are selected.
  • Category and option names are sample data; the real ones come from the API.
