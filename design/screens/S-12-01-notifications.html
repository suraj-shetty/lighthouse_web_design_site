Layout

  • 375: glass header with the title only, list grouped under TODAY / YESTERDAY / THIS WEEK / EARLIER (empty groups are left out). Row: 38 round leading image (actor avatar, or a group icon for orders, profile, social, admin), title (2 lines max), message, relative time; action buttons on their own line under the text, outlined secondary first and filled primary last. Unread rows are tinted. The Notifications tab carries the red dot.
  • 768: the same list in a centred column beside the rail; buttons move to the right of the row.
  • 1440: centred single column at reading width, buttons right-aligned, and a Refresh button in the header instead of pull-to-refresh.
  • The same screen is the Notifications tab of the reseller shell; the spec does not differ by role, so there is no role variant.
  • States: default, loading (skeleton rows), loading-more (spinner after the last row), empty, error.

Components used

  • Top header · IconButton glass (Refresh, from 768)
  • Avatar (38) or group icon tile · Button filled S (primary) · Button stroke S (secondary)
  • Skeleton · Spinner · single-line empty / error text · Nav badge dot · Toast (inline banner for notifications with no destination)

Motion

  • Rows rise in by section: --stagger-*; next 20 when within 200 px of the end: --stagger-*
  • Skeleton to content: --shimmer-*, --skel-*, --reveal-*; press: --press-*; navigation: --page-slide-*
  • Unread dot on the tab: --badge-pop-*. A push that arrives while this is open shows the dot at once, the banner S-12-06 (--toast-*), and refreshes the list after 3 s.

Accessibility

  • h1 "Notifications"; each section label is an h2 with its rows as a list.
  • Unread is exposed as text ("Unread.") and a dot beside the time, not only by the tint.
  • A row without buttons is one link; a row with buttons is a plain container, and each button is labelled with its notification ("View Quote: Quote received").
  • Times carry the full date in title / datetime; new items and "Loading more notifications" use polite live regions; the tab badge reads ", unread".

Decisions to confirm

  • Error shows the server message in the empty-line slot with no retry, as in Flutter. From 768 the header Refresh button doubles as the retry (F-12 open question: add a retry on web?).
  • Review requested: "Review" has no destination and "Deny" does nothing in Flutter (TODO in code). Both buttons are drawn inert.
  • Download Invoice only opens the order detail, as in Flutter.
  • Post and project notifications pass through the loaders S-12-04 / S-12-05 before the post (S-12-03) or project screen; the mockup links straight to the loaded screen.
  • Admin announcements have no destination: tapping the row shows the inline banner (S-12-06).
  • Submit Quote and Decline open the reseller screens S-19-04 and S-19-06.
  • Group icons: Flutter uses Material icons (Q-34). Used Invoice01 (orders), User (profile), Favourite (social), Notification03 (admin and default).
  • No "mark all as read", no delete, and no link to Manage Notification from this screen, as in Flutter.
