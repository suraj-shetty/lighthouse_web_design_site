Layout

  • Fourth tab of a brand or dealer profile (S-07-01), shown in the same profile frame as the other tabs: cover, summary and tab row, with the panel beside the summary from 1200.
  • 375: map on top (about 30% of the height) with a store pin for every location that has coordinates, then the list: icon tile, name, address, distance, and Call + Directions on the right, divided by hairlines. The map is left out when no location has coordinates (state no-map).
  • Callout (tap a pin): a card above the pin with name and address on the left, Call and Directions on the right, and an arrow to the pin. Tapping the pin again closes it.
  • 768: map above the list, wider.
  • 1440: master and detail. The list sits on the left, the map stays pinned on the right; the row of the selected pin is highlighted.
  • Brands list up to 10 locations with no further paging; a dealer lists only its primary showroom. A location without a name reads "Location"; distance shows only when the server sends one.

Components used

  • Embedded map (.map, pins, attribution) with zoom buttons and a callout card
  • IconButton solid (Call, Directions) · list rows with an icon tile
  • Skeleton · single-line empty and error text · Footer CTA bar · Tabs · Toast (call failures)

Motion

  • Callout open / close: --panel-*; buttons and pins: --press-*
  • Skeleton: --shimmer-*, --skel-*; toast: --toast-*
  • Map: drag and pinch to pan and zoom, no rotation; dragging or tapping the bare map closes the callout.

Accessibility

  • Tab panel labelled "Location". The list is the accessible equivalent of the map: every pin's details and actions exist as a list row.
  • The map is a labelled group; pins are buttons named by the location with aria-expanded; the callout is a non-modal group closed by Esc; zoom has buttons for keyboard and pointer users.
  • Buttons are labelled "Call {name}" and "Directions to {name}"; the selected row is marked with aria-current, not colour alone.
  • Call failures show the toast "Call failed" with the server message, "No number to dial was returned" or "Could not open the dialer" in a polite live region.

Decisions to confirm

  • Map tiles: the web tile provider is undecided (Q-29). The map is drawn as the kit's placeholder with the attribution "© OpenStreetMap contributors"; in dark theme it uses the dark tokens instead of colour-inverted tiles.
  • Zoom buttons are a web addition for pointer and keyboard users (Flutter has pinch only).
  • Row highlight for the selected pin is a web adaptation from the spec; list rows still do not select pins.
  • Masked calls on desktop (Q-28): Call opens a tel: link to a masked number; behaviour without a dialer is undecided.
  • Error shows the server message with no retry, as in Flutter.
  • Directions opens the location's Google Maps link in a new tab.
