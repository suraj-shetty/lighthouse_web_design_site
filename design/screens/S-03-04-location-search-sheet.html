Layout

  • 375 — glass bottom sheet fixed at 95% height: drag handle; search field with a clear button; "Use Current Location" row; divider; results area (list, skeleton or message). Lifts above the keyboard.
  • 768 / 1440 — popover under the Current Location field with the same search, row and results list (fixed maximum height).
  • States: default (empty search, empty results), selected (a location was already chosen: one checked row), results (suggestions for "Bandra"), loading (skeleton rows), locating (spinner and "Fetching current location...", row disabled), empty ("No results found"), error (toast; the sheet stays open).

Components used

  • Bottom sheet / popover
  • Search input with clear
  • Action row (Use Current Location, with busy state)
  • Radio result rows
  • Skeleton · Toast danger

Motion

  • Open / close — --panel-*; suggestions loading — --skel-*, --shimmer-*; row selection — --select-check-*; toast — --toast-*.

Accessibility

  • Dialog with the accessible name "Current Location" (the app shows no visible title).
  • Search is a combobox controlling the results; loading and "No results found" are announced through a live region.
  • "Use Current Location" is a button with a busy state. Focus returns to the location field on close; Esc, scrim and drag down close and clear the query.

Decisions to confirm

  • Suggestions are requested 400 ms after the last keystroke (as the app).
  • Device GPS becomes the browser location prompt; "permanently denied… Enable it from settings." maps to the browser's blocked-permission state.
  • The error toast shows one of the listed messages ("Location" / "Location permission denied"); the others reuse the same toast.
  • Suggestion texts are sample data from the places API.
