Layout

  • 375 — glass bottom sheet at 94% height: drag handle, title, subtitle, search field (focused on open), then a scrolling area — "Use Current Location" row (when a device location is known), search results or "Last Used Locations", or the no-selection placeholder. Full-width SAVE pinned at the bottom.
  • 768 / 1440 — side sheet from the right with the same content; SAVE pinned at the bottom of the sheet.
  • Default: the current draft (Bengaluru) is listed first under Last Used Locations, highlighted with --accent-tonal and a remove (trash) button. Up to 3 recent locations.
  • Tapping "Use Current Location" or a suggestion only sets the draft (row highlights, trash appears) — SAVE applies it. Tapping another Last Used row selects, saves and closes at once.
  • Searching: 5 skeleton rows after a 300 ms debounce. No matches: "No results found". Nothing known and nothing selected: offline-pin glyph, "No City Selected" and its body; SAVE then shows the toast "Error / Please select a city".
  • Error: toast with the server message; the list is unchanged.

Components used

  • Side sheet / Bottom sheet
  • Search input with clear
  • Location row (icon, title, sub-address, trailing remove) — default, selected
  • Button filled L (SAVE, loading)
  • Skeleton rows · Empty state · Toast

Motion

  • Open / close — --panel-*
  • Row press — --press-*
  • Suggestions loading — --shimmer-*
  • Toast — --toast-*

Accessibility

  • Dialog labelled "Location", described by the subtitle; initial focus in the search field.
  • Locations are a single-select group with selected state; the remove button is labelled "Remove selected location".
  • SAVE announces busy while saving; focus returns to the location selector on close.
  • Selection is shown by the tonal fill and the remove button, not colour alone; toasts are in a live region.

Decisions to confirm

  • The spec asks for the suggestions as a listbox; the mockup wires rows as a radio group — use listbox / option in the build.
  • Selected row uses --accent-tonal (spec); in the app the selected state is only the trash icon.
  • The clear (×) glyph is CancelCircle, as the app. Error copy is the server message (sample text).
  • Location permission timing on web is open (Q-97): "Use Current Location" is shown only once a device location is known.
