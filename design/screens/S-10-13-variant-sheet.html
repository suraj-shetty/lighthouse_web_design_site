Layout

  • 375 — bottom sheet opening at 60% height: handle, title, subtitle, groups (name, red "*" when required, wrapping option chips), DONE pinned.
  • 768 / 1440 — side sheet from the right beside the purchase column; a close button replaces the drag handle.
  • Groups are ordered by group index, options by option index.

Components used

  • Bottom sheet / side sheet
  • Filter chip (single-select per group)
  • Button filled L (DONE, disabled state)

Motion

  • Open / close — --panel-*
  • Option select — --select-check-*; press — --press-*

Accessibility

  • Dialog named "Variant". Each group is a radio group with its name as legend; required groups set aria-required (the "*" alone is not enough).
  • Selected state is exposed, not colour alone. Focus returns to the Variant selector.
  • DONE is disabled until every required group has a selection.

Decisions to confirm

  • Group and option names are sample data from the product's variant rows.
  • Closing by scrim, Esc or drag discards changes; DONE returns the selection and the product page updates title, images, SKU and price.
  • Desktop keeps the side sheet instead of inline groups in the purchase column, so DONE applies everything at once as in the app.
  • In the mockup, the disabled state enables DONE as soon as a Finish is picked.
