Appearance

Choose how Lighthouse looks on this device.

Layout

  • 375 — glass bottom sheet sized to content, above the safe area: drag handle; title; subtitle; three radio rows (title + explanation); full-width DONE.
  • 768 / 1440 — popover anchored to the Appearance row in Manage Account, same content.
  • States are the stored choice: system (default when nothing is stored), light, dark. No loading, empty or error state (local only).
  • This file is also the design for S-15-01 (the same sheet opened from Settings).

Components used

  • Bottom sheet / popover
  • Radio rows (title + explanation)
  • Button filled L (DONE)

Motion

  • Open / close — --panel-*; option — --select-check-*; DONE — --press-*.
  • The whole site re-themes live behind the sheet as an option is tapped; the sheet stays open.

Accessibility

  • Dialog named "Appearance"; the options are a radiogroup, each described by its explanation; the change is announced.
  • Focus returns to the Appearance row; Esc, scrim, drag down and DONE all close (there is no separate save step).

Decisions to confirm

  • "System" follows the browser / OS colour-scheme preference; the choice is stored per browser.
  • Q-25: the app wipes the theme choice on sign-out — should it survive on web?
  • In the mockup, switch the theme with the board's Theme control; tapping an option only moves the radio.
  • Selected radio uses the shared Radio component (inverse fill); the spec names --accent.
