Layout

  • 375 — glass bottom sheet at 92% height: drag handle, title, subtitle, scrolling list of rows (avatar · full name over "@username"), hairline between rows.
  • 768 / 1440 — popover (380 wide, up to 70% of the viewport height) anchored to the like count it was opened from; the list scrolls inside it.
  • Rows without a user name show the name only. 20 rows per page; a spinner row appears while the next page loads.
  • The sheet is only reachable when the like count is not 0; the empty copy appears after a failed first load.

Components used

  • Bottom sheet / Popover
  • Avatar
  • List row (link to profile)
  • Skeleton rows · Spinner
  • Toast

Motion

  • Open / close — --panel-* (sheet slides up; popover fades and scales from the like count)
  • Row press — --press-*; skeleton — --shimmer-*
  • Row tap — --page-slide-* to the profile

Accessibility

  • Dialog named "Likes", described by the subtitle; each row is a link whose name is the full name plus handle.
  • aria-busy while loading; loading more is announced.
  • Focus is trapped and returns to the like count; Esc closes.

Decisions to confirm

  • Spec allows a side sheet, a popover or a centred modal from 768; a popover on the like count was chosen because the list is short and contextual.
  • In the app the profile opens on top of the sheet; on web the row navigates to the profile and the popover closes.
  • Verified badges are not shown here (avatar only, as the app).
