Layout

  • 375 — blurred gradient header with only a round glass back button; content scrolls beneath it. Space sections separated by hairlines. Each section: space title → square rounded media carousel ("n/N" pill top-right when there is more than one media) → dots → description (3-line clamp + View More / View Less) → "PRODUCTS USED" for the media on show: thumbnail · brand tag · product title (2 lines) · "Price" with the value right-aligned.
  • 768 — the same sections in a centred 600 column, with a row of space chips at the top for jumping.
  • 1440 — each space is a two-column block: square carousel left (460), title, description and products right. The chip row lists the spaces; the square media is never stretched full width.
  • Changing the media (dots, or arrows on hover from 768) swaps the PRODUCTS USED list; a media without tagged products has no list; a space without media shows a square placeholder tile; inline video plays muted with pause, scrubber and mute.
  • Loading (skeleton) and error (message + Close, plus the toast) exist for URL entry (Q-07). Empty: icon tile, "No spaces yet" and its body. State media error: broken-image and video-off glyphs, glyph tiles for product thumbnails.

Components used

  • Top header (gradient glass) · IconButton glass (back)
  • Image gallery (carousel, image count badge, dots, previous / next)
  • Button text (View More / View Less)
  • Product list row · Tag / Label (brand)
  • Chips (space jump list, from 768)
  • Empty state · Skeleton · Toast

Motion

  • Push — --page-slide-*
  • Carousel — --tabs-* (dots), --tab-panel-* (media)
  • Products list change — --text-swap-*
  • Description expand — --resize-dur
  • Media tap — --mediaview-open-dur (S-06-03)

Accessibility

  • Main landmark with a visually hidden h1 (the app shows no project title here); each space title is an h2; "PRODUCTS USED" is an h3.
  • Carousel controls are labelled and each slide is "n of N"; the products region is a polite live region because it changes with the carousel.
  • Products are a list; prices are read with their currency; product rows are not interactive.
  • Inline video autoplays muted: a pause control is provided and reduced motion disables autoplay.

Decisions to confirm

  • The space chip row from 768 is the "optional in-page list" from the spec; drop it if not wanted.
  • The tab bar is hidden under 768, matching S-06-01 and the app's pushed screens.
  • Glyphs not in ICONS.md: broken-image and image placeholder → Image02, video-off → Video01, product placeholder → Package, empty state chair → Sofa03.
  • Product rows are not links to the marketplace (Q-62).
  • In the mockup the carousel is driven by dots and arrows (no swipe).
