Accessibility

  • h1 "Active Order" with the order number beneath it; "Cancel" is named "Cancel order".
  • Quotes are one radiogroup named "Dealer quotes"; each option reads dealer label, final price, unit price, delivery and validity.
  • APPROVE TO PROCEED is disabled until a quote is selected, with the hint "Select a quote to approve" for screen readers.
  • Status is text in a pill, never colour alone. The sticky bar leaves room so focused content is not covered.
