  • 768: same order in a centred column; stat cards in one row.
  • 1440: header block and stats in a pinned card on the left (with Contact as a button), section cards on the right.
  • Shown only for professional roles. This file is also the own-profile view (S-13-04): state own is identical without Contact, and back returns to My profile.
  • Stats, rows and whole sections without a value are left out (state empty); the budget card hides when the amount is 0 or less.

Components used

  • Top header · IconButton glass (back) · Avatar · Status pill (Available) · Rating · verified badge
  • Metric cards (description list) · Tag (skills, budget pill) · Key / value list · tick rows
  • Button text (View All, Retry) · Button filled (Contact) · Footer CTA bar · Skeleton

Motion

  • Back: --page-slide-*; press on the certificate card and buttons: --press-*
  • Contact sheet and the read-only certificate sheet: --panel-*

Accessibility

  • h1 is the title "About {first name}"; each section title is an h2; stats and work preferences are description lists.
  • "Available" and "Verified professional" are text, not colour only; the rating is read as "Rating 4.8 out of 5".
  • Focus order runs top to bottom, then Contact.

Decisions to confirm

  • Loading and error are not in Flutter (the screen reuses the loaded profile). They are drawn because the web page can be opened from its own URL (Q-07); the error shows the server message with Retry, the pattern Manage Notification uses.
  • Dark theme: cards use the weaker surface (--bg-weak), as the Flutter code comment asks.
  • Certificate card opens S-13-21 in its view-only mode; View All opens the read-only S-13-20 list (shown when there are more than 2 certificates). Both belong to the own-profile feature.
  • Contact icon: Contact01 is not in ICONS.md; Call02 is used.
