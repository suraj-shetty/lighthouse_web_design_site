Layout

  • 375 — glass bottom sheet sized to its content: drag handle, title, subtitle, nine single-select rows (label left, radio right, hairline between), full-width Report button.
  • 768 / 1440 — the same content as a centred dialog (440 wide), replacing the options menu it was opened from.
  • The button stays disabled until a reason is chosen; the chosen row turns semibold and its radio fills. Tap any reason in the Default state to see it enable.
  • Error keeps the sheet open with the selection intact and shows the toast.

Components used

  • Bottom sheet (under 768) / Modal dialog (from 768)
  • Radio rows (single select)
  • Button filled L — default, disabled, loading
  • Toast — success "Reported", danger "Error"

Motion

  • Open / close — --panel-* (sheet) · --modal-* (dialog)
  • Reason select — --select-check-*
  • Button press — --press-*; toast — --toast-*

Accessibility

  • Dialog named "Report" and described by the subtitle; reasons are a radio group labelled by the subtitle, arrow keys move the selection.
  • Disabled submit exposes aria-disabled; while sending it is busy and announces "Reporting".
  • Focus is trapped and returns to the card's "…" button; Esc, scrim tap and drag down close without reporting.
  • Selection is shown by weight and the filled radio, not colour alone.

Decisions to confirm

  • Spec lists the button with --radius-12; the design keeps the pill button of the design system. Confirm.
  • Error toast body is the server message — "Network error occurred" is sample text.
  • On success the reported item is removed from every loaded feed tab (not shown in the mockup).
