Layout

  • 375 — as the app: back and title, a scrolling row of eight status chips, then rows separated by hairlines: thumbnail (30% width), brand tag, SKU, title on one line, quantity, status.
  • 768 — the list becomes one raised card; each row puts the status pill and a chevron at the right end; a Refresh button replaces pull-to-refresh.
  • 1440 — master–detail: the list on the left, a sticky summary of the selected order on the right (product, order number, status, quantity, MRP, placed date, progress timeline, VIEW ORDER).
  • States: default "Requested" selected · loading-more spinner row at the end of the list · cancelled arriving after a cancel: "Cancelled" chip + toast · loading six skeleton rows · empty per-status empty text · error the empty placeholder + toast.
  • The chips work in the mockup: each status has its own sample rows and its own empty text.

Components used

  • Navigation shell (shared) · Top header (glass)
  • Chip as status tabs (scrolling tablist) · IconButton glass (Refresh, from 768)
  • Order row · Tag (brand) · Status pill
  • Card with key / value list · Steps (1440 panel) · Button filled L
  • Skeleton · Empty state · Spinner (next page) · Toast

Motion

  • Chip select — --tabs-*; list swap — --tab-panel-*
  • Rows entrance and next page — --stagger-*; skeleton — --skel-*, --shimmer-*, --reveal-*
  • Row to detail — --page-slide-* under 768, --panel-* from 768; toast — --toast-*

Accessibility

  • h1 "My Orders"; chips are a tablist named "Order status" with the selected state announced.
  • Each row is one link named "{title}, quantity {n}, {status}"; thumbnails are decorative; a missing thumbnail is announced as "Image unavailable".
  • Loading and empty are polite status regions. Focus order: back, chips, rows.
  • Status is text in a pill, not colour alone.

Decisions to confirm

  • Error (F-11-Q7): the app swallows the failure and shows the empty state. Following Q-06, web shows the same placeholder plus the toast "Error / Network error occurred"; Refresh retries.
  • The 1440 summary panel, its progress timeline and the label "VIEW ORDER" are web additions; the spec asks for the selected order's detail in the right panel. Confirm the summary, or embed the full detail.
  • Glyph: the empty state uses File02 for the app's draft-document icon.
  • Brand tags are capitalised as the app does (first letter only), e.g. "Asian paints".
  • "GO TO MY ORDERS" opens stale filters in the app (F-11-Q1); the mockup links open the default filter.
  • Under 768 the glass tab bar stays visible here because the screen has no bottom action bar; the app hides it on pushed screens.
