Area

Add the project's area measurements and counts.

Layout

  • 375 — tall glass sheet: handle → title → subtitle → four area fields (label above; number input and unit select side by side) → three count rows (label left, narrow input right) → full-width SAVE.
  • 768 / 1440 — side sheet, same order (the sheet is too narrow for two area fields per row).
  • States: default (saved values pre-filled, whole numbers without decimals) and empty (all blank). SAVE is always enabled; saving everything blank clears the Area row.
  • Loading and error do not apply — nothing is fetched and the app has no inline validation.

Components used

  • Side / bottom sheet · IconButton glass (close)
  • Text field (numeric) · Select (unit: sqft, sqm, sqyd, acre) · Button filled L (SAVE)

Motion

  • Open / close — --panel-*
  • Button press — --press-*

Accessibility

  • Dialog labelled by its title. Each number input is labelled by its field name; each unit select is named "<field> unit".
  • Decimal / numeric input modes. Focus order runs top to bottom with SAVE last.

Decisions to confirm

  • Non-numeric text is dropped on save with no message, and there are no min / max or negative checks (as the app).
  • The form row counts only the four area fields ("3 measurements"); Floors, Buildings and Units are saved but not reflected there.
  • The unit menu is the browser select; close button is a web addition.
