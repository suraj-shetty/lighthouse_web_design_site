Layout

  • Two non-blocking banners, shown over whatever screen is open (Home feed here).
  • (1) Foreground push banner (states push, push-title-only): a push that arrives while the site is open. 375: card at the top, inset from the edges, bold title with the message under it. 768 / 1440: the standard toast corner, width capped at 400. Dismisses after 3 s.
  • (2) Inline fallback banner (state inline): shown when a tapped notification has no destination (admin announcements, unknown events). 375: card at the bottom, above the tab bar. 768 / 1440: the toast corner. Dismisses after 4 s.
  • Title fallbacks: "Light House" for a push with no title, "Lighthouse" for a notification with no title. An empty push body shows the title only.

Components used

  • Toast, neutral (dark surface in both themes)

Motion

  • Enter / leave: --toast-*; the unread dot on the Notifications tab appears with --badge-pop-* at the same moment; tap on banner (1): --press-*, then --page-slide-*.

Accessibility

  • Polite status region; it never takes focus.
  • When the push has a payload, banner (1) is a focusable link named by its title; without one it is plain text. Banner (2) is never interactive.
  • Nothing is lost when a banner times out: the same item is listed in Notifications (S-12-01).

Decisions to confirm

  • Browser push (Q-23): with OneSignal web push the foreground notification event is shown as this in-page banner and the browser's own notification is suppressed, mirroring the app. When the tab is in the background the browser shows its native notification instead (not app-drawn).
  • Both banners keep a dark neutral surface with light text in light and dark themes, as in Flutter (--element-bg-tag-dark / --element-fg-tag-dark; there is no dedicated toast surface token).
  • Leading glyphs (Notification03, InformationCircle) follow the kit's toast layout; the Flutter snackbar has text only.
  • Swipe to dismiss on touch; from 768 the banner only times out (no close button in Flutter).
  • Banner (1) routes with the push payload using the F-12 routing tables; the sample opens the buyer order detail.
