Layout

  • 375 — full screen, as the app's pushed screen: header (back · title · SAVE pill) → title → description → info card (with an "Add" pill in add mode) → 2-column grid of square tiles (remove chip top-right, tag pill bottom-left).
  • 768 — large modal over the project form; media grid in 3 columns.
  • 1440 — the same modal in two columns: title and description on the left, info card and media grid on the right. The project form stays visible behind it.
  • States: default (new space, blank → SAVE disabled, no grid), filled (media added; images carry a tag pill, videos none), existing (EDIT SPACE: only title and description editable, media read-only with a play glyph on videos), existing-empty ("No media attached to this space."), loading (flat tile blocks until thumbnails resolve — no skeleton, as the app).

Components used

  • Full-screen / modal panel · IconButton glass (back) · Button filled S (SAVE, Add)
  • Textarea (title, description) · Card (info)
  • Media tile · IconButton glass on media (remove) · tag-count pill

Motion

  • Open / close — --page-slide-* under 768, --modal-* from 768
  • Media picker — --panel-*; tag screen and viewer — --mediaview-open-dur
  • Button press — --press-*

Accessibility

  • Heading = title. Title is labelled "Title" and required; Description is labelled "Description". Disabled SAVE is described ("Title required").
  • Tiles: image alt "Space media n"; remove buttons are named; the tag pill is a button announcing the count.
  • Focus order: back → SAVE → title → description → Add → tiles.

Decisions to confirm

  • Header reads "ADD SPACES" even for one space, kept verbatim (Q-69).
  • Back discards without confirmation (Q-67). A new space may be saved with no media in create mode but not in edit mode (Q-65).
  • Existing-space tiles open S-06-03 (tagged-products viewer, Home feature).
