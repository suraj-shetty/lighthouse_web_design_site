Select a timeframe

Layout

  • 375: bottom sheet with rounded top corners: drag handle, title, 4 radio rows, full-width primary button. Height wraps the content.
  • 768 / 1440: popover anchored to the timeframe pill that was tapped, same content.
  • The state switch shows which period the originating card had applied (Monthly by default); that option is pre-selected.

Components used

  • Bottom sheet / popover
  • Radio (4 options)
  • Button filled L (APPLY)

Motion

  • Open / close: --panel-*; radio change: --select-check-*; button press: --press-*

Accessibility

  • Dialog named by its title; focus moves in and returns to the originating pill on close.
  • Options form a radio group moved through with the arrow keys; Esc, the scrim and (mobile) drag down close without applying.

Decisions to confirm

  • Tapping an option only selects it; APPLY closes and returns the choice, and the card updates only if the period changed (no network call).
  • Loading, empty and error do not apply (no network).
  • The spec names --accent for the selected radio; the kit's Radio component fills with --bg-inverse, and that component is used unchanged.
