Edit

Layout

  • 375 — glass bottom sheet sized to content: drag handle, rows with a hairline between them.
  • 768 / 1440 — menu anchored to the "…" button of the card it was opened from.
  • Author sees Edit (post / project only) and Delete; everyone else sees Report and Block User.

Components used

  • Bottom sheet / popover menu
  • Menu row (icon, label, trailing arrow)

Motion

  • Open / close — --panel-* (sheet slides up on mobile; menu fades and scales from its trigger from 768)
  • Row press — --press-*
  • Delete opens S-05-06 on top — --modal-*; Report / Block replace this menu with their sheet — --panel-*

Accessibility

  • Menu semantics named "More options"; rows are menu items.
  • Esc, scrim tap and (mobile) drag down close it; focus returns to the "…" button.
  • Delete is marked with the danger colour and its label, not colour alone.
