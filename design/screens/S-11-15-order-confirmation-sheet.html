Layout

  • 375 — content-height scrolling glass sheet: handle, title, question, recipient block (Lighthouse card or the selected dealer cards), "Delivery Location *" with Select / Change and the location card, "Add a note (Optional)" with a text area, pinned "SEND REQUEST".
  • 768 / 1440 — side sheet from the right, 440 wide, same stack; the footer stays pinned. Recipient block and form stay stacked.
  • States: default via Lighthouse, first saved location preselected · dealers two dealers selected · empty no saved location: dashed "Tap to select delivery location", action "Select", SEND REQUEST disabled · loading · error (toast, sheet stays open).

Components used

  • Bottom sheet / side sheet · IconButton glass (close)
  • Option card (Lighthouse) · Select card (dealer, location) · Status pill "Open Now" · Tag with check
  • Button text (Select / Change) · Textarea
  • Button filled L (disabled, loading) · Toast danger

Motion

  • Open / close — --panel-* (bottom sheet under 768, side sheet from 768)
  • Button press — --press-*; toast — --toast-*
  • Location picker (S-11-16) opens over this sheet — --panel-*; on success, push Order Request Sent (S-11-17) — --page-slide-*

Accessibility

  • Dialog named by the title and described by the question.
  • "Delivery Location" is marked required in text for screen readers, not only with "*".
  • A disabled SEND REQUEST says a delivery location is needed; while sending, the button is busy.
  • The note field is labelled "Add a note (Optional)"; focus returns to the trigger on close.

Decisions to confirm

  • "via lighthouse" keeps the lowercase spelling from the app (F-11-Q12 is unanswered).
  • While saved locations load, the card shows the empty prompt (no skeleton), as the app.
  • When seller ids arrive without seller objects the app shows "2 dealer(s) selected" instead of cards; not drawn separately.
