Layout

  • 375 — tall glass sheet: handle → title → subtitle → scrolling option rows (radio for single, checkbox for multi) → full-width SELECT (single) or ADD (multi).
  • 768 / 1440 — side sheet, same order.
  • One sheet, eleven callers. Each state is one caller with its own title, subtitle, mode and options: Nature (max 3), Project Scope, Design Style (max 5), Cost Range, Cost Type, Facing, Spaces Covered, Site Context, Sustainability, Certifications, and the credit Role.
  • Further states: loading (first open per list), empty and error ("No options found"; error adds a toast), limit ("Limit reached" toast when a 4th nature is tapped), exclusive ("Selection updated" toast after an exclusive option such as None clears the rest).
  • Choosing "Other" reveals a free-text field on the form, not here.

Components used

  • Side / bottom sheet · IconButton glass (close)
  • Radio rows · Checkbox rows · Button filled L (SELECT / ADD) · Skeleton rows · Toast

Motion

  • Open / close — --panel-*
  • Radio and checkbox — --select-check-*
  • Toasts — --toast-*; skeleton — --skel-*

Accessibility

  • Dialog labelled by its title and described by the subtitle; capped lists add "Pick up to n." for screen readers.
  • Radio group or checkbox group; the confirm button exposes its disabled state when nothing is selected.
  • Exclusive-option side effects are announced through the toast live region. Focus returns to the originating row.

Decisions to confirm

  • An empty selection cannot be confirmed, so an optional value cannot be cleared here (Q-64).
  • Option names are sample data; the lists come from the category API by tag.
  • Close button is a web addition.
