Layout

  • 375 — glass header (back · title). Horizontal media carousel (tiles 60% wide × 30% high, remove chip top-right) → caption with n/500 counter → options card (Tag People, Location) → sticky full-width SHARE / SAVE above the tab bar.
  • 768 — one centred column; the carousel shows more tiles.
  • 1440 — two columns: media on the left as a 2-up grid in publishing order, caption + options on the right, primary button right-aligned in the sticky bar.
  • Roles: Tag People only for professionals. Edit adds saved media (video posters with a play glyph, no playback) and a trailing "+" tile.
  • States: default (create, valid), empty (blank caption → SHARE disabled), edit, edit-empty (only the "+" tile → SAVE disabled), loading (button busy; S-09-07 blocks the page), error (toast, form untouched).

Components used

  • Top header · IconButton glass (back)
  • Carousel tile · IconButton glass on media (remove, move earlier / later, play) · drag grip
  • Textarea + counter · Card with tap-to-edit rows
  • Sticky CTA bar · Button filled L (SHARE / SAVE, disabled, loading) · Toast

Motion

  • Tile lift on drag and button press — --press-* (no reorder recipe exists — Q-71)
  • Pickers — --panel-*; submit loader — --modal-*; toasts — --toast-*
  • Push / pop — --page-slide-* (desktop --panel-*)

Accessibility

  • Focus order: back → tiles (remove, move earlier, move later) → caption → Tag People → Location → primary button.
  • Keyboard reorder: every tile has "Move earlier" / "Move later" buttons; the first and last are disabled at the ends. Drag is an enhancement.
  • Caption is labelled "Caption", required, with the counter in a polite live region. The disabled button is described ("Caption required").
  • Rows are buttons announcing label and value; the location clear button is a separate control named "Clear location".

Decisions to confirm

  • Move earlier / later buttons are a web addition (Q-71).
  • No discard confirmation on back, as in the app (Q-67).
  • SAVE in the mockup shows the "Post updated" toast; in the product it runs S-09-07 and returns to Home.
