Layout

  • 375: glass bottom sheet (up to 90% height): handle, title and subtitle, content, full-width button pinned above the safe area.
  • 768 / 1440: side sheet from the right over Awards & Certificates.
  • Grouped card of three rows (label left, value right): Name, Issuing Organisation, Issue Date; the error line sits under its row. Then the dashed upload box, the attached files, and one or two stacked buttons.
  • States: add empty form, "ADD" · validation the three required messages · existing read-only values, "EDIT" + "REMOVE" · editing "UPDATE" + "CANCEL" · loading uploading and saving, everything disabled · view title is the certificate name, no subtitle, no upload box, no buttons · error toast, sheet stays open.

Components used

  • Bottom sheet / side sheet · IconButton glass (close)
  • Grouped form rows (text field, date trigger)
  • File drop zone · Button filled M ("Browse file")
  • Uploaded-file row with remove IconButton or chevron
  • Button filled L (with loading) · Button stroke L · Toast (danger)

Motion

  • Open / close: --panel-* (slides up under 768, slides in from the right from 768).
  • Read ⇄ edit: --reveal-*; attachment remove, --icon-swap-*.
  • Issue Date opens S-13-26: --modal-*; "Browse file" opens S-13-22, --panel-*; attachment preview, --mediaview-open-dur.

Accessibility

  • Dialog named by the sheet title; focus moves into the sheet, is trapped, and returns to the row it was opened from; Esc and the scrim close it.
  • Every field has a visible label; each error is linked with aria-describedby and the field is marked invalid.
  • Attachments are a list; preview and remove buttons carry the file name.
  • REMOVE is named "Remove certification" and marked by colour and label.
  • While saving, controls are disabled and the primary button announces "Saving".

Decisions to confirm

  • Q-111: Credential URL is not shown (commented out in the app, never sent).
  • Validation copy is verbatim, including the spelling "organization" next to the label "Issuing Organisation".
  • Image and PDF attachments open the shared viewers (S-05-11 / S-05-13); S-13-25 is only for other file types.
  • In the read state the upload box is shown but disabled (the app shows it inert until EDIT). Hide it instead?
  • From 1440 "Browse file" should open the system file chooser directly (S-13-22 web adaptation).
  • Name and organisation wrap to two lines in the app; here they are single-line inputs.
