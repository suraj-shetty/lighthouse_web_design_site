Layout

  • Full-screen scrim with a centred white spinner and no text, at every width.
  • States: default (saving: photo upload / remove, Work Mode save) · loading-options (Specializations, Service Type and Collaboration options loading before their sheet opens) · error (loader gone, error toast).
  • From 768 the control that started the action may show inline progress instead (spec allows either); the scrim version is drawn here.

Components used

  • Modal scrim
  • Spinner (40, white on scrim)
  • Toast (danger)

Motion

  • Scrim in / out: --modal-*
  • Spinner: linear rotation
  • Error toast: --toast-*

Accessibility

  • role="status" with the text alternative "Saving…" or "Loading…"; the page behind is aria-busy in build.
  • Not dismissible; focus stays on the control that started the action and is not lost when the loader closes.
  • Reduced motion: the spinner keeps turning (it is the only progress signal).

Decisions to confirm

  • In this mockup, pressing the scrim closes the loader so the flow can continue; in the product it cannot be dismissed.
  • "Saving…" / "Loading…" are screen-reader text only (the app has no copy).
