Layout

  • 375: glass bottom sheet capped at half the screen height: drag handle, title row with a round glass close button, subtitle, scrolling list of rows (avatar · display name over "@username"), hairline between rows.
  • 768 / 1440: popover (360 wide) anchored to the card header it was opened from.
  • The author is always first and carries a trailing "Author" label; a tagged entry equal to the author is not repeated.
  • State many shows the list scrolling inside the height cap, including a row with no user name.
  • No loading, empty or error state: the data is already in the feed item and the sheet only opens when someone is tagged.

Components used

  • Bottom sheet / Popover
  • IconButton glass (close)
  • Avatar
  • List row (link to profile) with trailing text label

Motion

  • Open / close: --panel-*
  • Row press: --press-*; row tap closes the sheet, then --page-slide-* to the profile

Accessibility

  • Dialog named "People", described by the subtitle.
  • Rows are links named by display name and handle; the first also announces "Author".
  • Close button label "Close"; Esc closes; focus is trapped and returns to the card header.
  • Rows without a user id are not links.

Decisions to confirm

  • A missing or broken avatar shows the default profile image (asset to be supplied).
  • Verified badges are not shown here (avatar only, as the app).
