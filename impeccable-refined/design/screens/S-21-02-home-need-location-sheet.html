Layout

  • 375: the Marketplace location sheet (S-10-02) in pick mode: glass bottom sheet at 94% height, handle, title, subtitle, search field, scrolling list, ADD pinned at the bottom.
  • 768 / 1440: side sheet from the right over the step screen; the list scrolls inside and ADD stays pinned. A close button replaces the drag handle.
  • List order as S-10-02: "Use Current Location", search results while typing, Saved Addresses, Last Used Locations. Saved Addresses hide while there is search text.

Components used

  • Bottom sheet / side sheet, Search input (with clear), location row and group headings (from f-10.css, unchanged).
  • Button filled L (ADD), IconButton (clear selection, danger), Skeleton rows, Empty state, Toast (danger).

Motion

  • Open / close: --panel-*. Results: --shimmer-*. Row and button press: --press-*. Toast: --toast-*.

Accessibility

  • Dialog named "Select your location" and described by the subtitle. Focus moves to the search field, is trapped, and returns to the location pill, which then reads "Location: name". Esc closes without changing the step.
  • Group headings are real headings; each row is one button named by its name and address; the selected current-location row exposes a pressed state. The delete glyph is labelled "Clear selected location".
  • "No results found" and "Searching" are announced politely.

Decisions to confirm

  • ADD always returns the draft and never changes the Marketplace city. With no draft (empty state) it shows the toast "Error" / "Please select a city" and the sheet stays open.
  • The need's current location is the draft when the sheet opens, but the app shows no mark for it in the list unless it is the GPS location (current-selected state). Kept as the app.
  • A Saved Address or Last Used row commits and closes in one tap; a search result or "Use Current Location" only sets the draft and needs ADD.
  • There is no saving state: nothing is written to a server from this sheet. The error state is the place-details toast with sample text.
  • Leading glyphs (navigation-03 for current location, clock-01 for recent) are the web choices already made on S-10-02; the app uses one pin glyph.
