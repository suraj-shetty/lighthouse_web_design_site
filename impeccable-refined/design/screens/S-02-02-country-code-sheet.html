Layout

  • 375: glass bottom sheet at 90% height: drag handle, title, subtitle, search field (all fixed), then the scrolling list (flag · "Name (dial code)" · radio). Lifts above the keyboard.
  • 768 / 1440: popover anchored to the country trigger of the phone field: same header and search, list scrolls inside a fixed maximum height.
  • States: default (all 158 countries from the app, India checked), search (query "uni": name or dial code contains it), empty (no match: empty list, as the app). No loading or error state: the list is static.

Components used

  • Bottom sheet / popover
  • Search input
  • Radio rows with flag

Motion

  • Open / close: --panel-* (sheet slides up under 768; popover fades and scales from its trigger from 768).
  • Row selection: --select-check-*, then the sheet closes.

Accessibility

  • Dialog named by its title; focus is trapped and returns to the country trigger; Esc, scrim and (mobile) drag down close without change.
  • Search is labelled "Search country"; filtering is immediate. The list is a radiogroup, arrow-key navigable; flags are decorative.
  • With no match, "No countries match" is announced to screen readers.

Decisions to confirm

  • The empty state is visually blank in the app (no message). Add a visible "No results found" line on web?
  • Rows whose dial code equals the current one are all checked (e.g. +1 would check both United States and Canada): as the app.
  • Selected radio uses the shared Radio component (inverse fill); the spec names --accent.
