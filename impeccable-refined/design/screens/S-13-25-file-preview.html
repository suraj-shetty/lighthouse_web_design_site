Layout

  • Centred dialog at every width: title, the attachment name, its stored value (up to four lines), one button.
  • Single state: text only.

Components used

  • Modal / Dialog
  • Button filled M ("Close")

Motion

  • Open / close: --modal-*.
  • Button press: --press-*.

Accessibility

  • Dialog named by its title; focus trapped and returned to the attachment row.
  • Esc, the scrim and "Close" all close it.
