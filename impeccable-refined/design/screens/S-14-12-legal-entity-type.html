Layout

  • 375: glass bottom sheet over the scrim: drag handle, title, subtitle, single-select option list, "Save".
  • 768 / 1440: side sheet from the right over Manage Account (440 wide, no drag handle); same order, actions pinned to the bottom.
  • default saved value pre-selected · unset nothing saved yet · saving options locked, spinner in the button · server-error.

Components used

  • Bottom sheet / side sheet
  • IconButton glass (close)
  • Radio option rows (glass pill, label left, control right)
  • Button filled L (Save, with loading)
  • Toast danger

Motion

  • Open / close: --panel-*
  • Button press: --press-*
  • Error toast: --toast-*
  • Option select: --select-check-*

Accessibility

  • Dialog named by its title; focus moves into the sheet, is trapped, and returns to the Manage Account row that opened it; Esc or the scrim closes without saving.
  • While saving the primary button is disabled and announces its busy label; toasts are announced through a polite live region.
  • Options are a radio group (arrow keys move the choice) labelled "Legal Entity Type"; the selected row also gets a stronger border, so colour is not the only signal.

Decisions to confirm

  • unset: in the app a "Save" tap with nothing selected is silently ignored; on web the button is disabled until a choice is made: confirm.
  • Unchanged selection closes without a request.
  • State server-error shows the sheet as it stays after a failed request, with the "Error" toast (server message, else "Network error occurred" / "Something went wrong. Please try again later."). No retry control, as the app.
