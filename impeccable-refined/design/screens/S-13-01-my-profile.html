Layout

  • 375: mirrors the app: cover across the top quarter with glass Back and More over it, avatar centred on the cover's lower edge (round; 3:2 logo tile for Brand and Reseller) with the verified badge, name, @username, role, two-line bio that expands on tap, rating and Featured chips, three stat tiles, About row (professionals), then the four-tab bar pinned under the top bar and a 3-column square grid.
  • 375 scroll: once the identity block passes under the bar, the name pill (small avatar, name, @username) fades in between Back and More.
  • 768: floating glass bar above a rounded cover; same centred identity; tabs sit left with icon beside label; grid 4 columns.
  • 1440: wide header inside a 1120 content width: identity left-aligned under the cover, stat tiles and the About row in a right column; grid 4 columns; Location tab is list left, map right; More opens as a menu anchored to its button.
  • Roles: Professional (Projects / Experience / Team, About row, Work · Posts · Videos · Saved), Homeowner (Posts / Followers / Following, same tabs), Brand (Projects · Inspirations · Shop placeholder · Location, up to 10 locations), Reseller (Brands / Orders / Response, Projects · Posts · Shop · Location with the primary showroom only).
  • States: default · loading (whole-page skeleton) · tab loading (12-cell grid skeleton; Location = map block + 4 rows) · loading more (spinner cell at the grid end) · empty (stat fallbacks, About "No details added yet", per-tab text) · error (placeholder header "User" / "@username" / "Specialization not specified" + toast; Location tab shows the raw error text).

Components used

  • Top header · IconButton glass (Back, More, Directions)
  • Avatar + verified badge · Tag (rating, Featured) · Rating star
  • Stat tiles (.stats / .stat) · About summary row (feature CSS)
  • Tabs (underline, icon + label) · Image grid (.tiles) with multiple-image and video marks
  • Embedded map + location rows · Section header + shop tiles (summary of S-07-08)
  • Skeleton · Spinner · line empty text · Toast (danger)

Motion

  • Back / grid cell / About row: route change --page-slide-* on mobile, --panel-* crossfade from 768
  • Name pill on scroll: --reveal-*
  • Tab change: --tabs-*, panel --tab-panel-*
  • Bio expand / collapse: --panel-*; press on rows, tiles and buttons, --press-*
  • More menu: --panel-*; skeleton to content, --shimmer-*, --skel-*; next page of the grid, --stagger-*; toast, --toast-*

Accessibility

  • One h1: the full name. Stat tiles are a list of value + label. The name pill is decorative (hidden from assistive tech).
  • Tabs are a tablist with tab panels; arrow keys move between tabs in build. Focus order: Back, More, bio, About row, tabs, grid.
  • Grid cells are links named by type and title ("Project, multiple images: …", "Video: …"); the corner marks are not the only signal.
  • Loading blocks carry aria-busy; the load-more spinner and Location error are status text; the toast is a polite live region.
  • Bio is a toggle button; Directions links are labelled with the location name and open in a new tab.

Decisions to confirm

  • Grid is 3 columns on mobile and 4 from 768 (brief); the spec table says 4–5 on tablet and 6 on desktop.
  • Error state follows Q-06: the app's placeholder header plus a toast, no retry control. Grid failures fall through to the empty text as in the app.
  • Glyphs not in ICONS.md: Work → Briefcase02, Menu01 (Posts / Inspirations) → GridView, Savings (Saved) → Bookmark02, Folder01 (Projects) → FolderOpen, Store01 → Store02, Briefcase01 → Briefcase02, copy / play marks → Copy01 / PlayCircle. The app's experience fact uses ShoppingBag01: kept.
  • About row links to S-07-07 (same widget as S-13-04, designed once).
  • Brand and Reseller avatars are shown as monogram logo tiles (sample art). Default cover and avatar art are token placeholders standing in for default_cover.png / default_profile.png.
  • Reseller Shop tab is a summary of S-07-08 (owned by F-07); Brand Shop tab is the app's placeholder text in every state (F-13-Q14).
  • Stat counts are shown unformatted (the app's number formatting for large counts is not in the spec).
  • More is hidden while the profile is loading (the app's button is a no-op until data arrives).
