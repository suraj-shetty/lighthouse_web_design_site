Layout

  • 375: glass sheet (opens at 75%): handle → title → Role picker → Name → Company → Lighthouse Profile picker → full-width SAVE.
  • 768 / 1440: side sheet, same order.
  • States: default (Add Credit, blank → SAVE disabled), filled (Role and Name set → SAVE enabled), edit (Edit Credit with the tapped credit, a linked profile shown as @username with a clear button).
  • Role opens S-09-11 (Role); Lighthouse Profile opens S-09-18. Linking a profile does not fill Name. Loading, empty and error do not apply.

Components used

  • Side / bottom sheet · IconButton glass (close)
  • Select (picker rows) · Text field · Button filled L (SAVE, disabled)

Motion

  • Open / close: --panel-*; nested pickers, --panel-*
  • Button press: --press-*

Accessibility

  • Dialog labelled by its title. Every input has a visible label; Role and Name are marked required.
  • Picker rows are buttons announcing label and value. Disabled SAVE is described ("Role and name are required"). Focus is trapped and restored.

Decisions to confirm

  • The required mark (*) on Role and Name is a web addition: the app shows no marker.
  • No validation messages; Name and Company are capped at 100 characters with no counter.
  • Close button is a web addition.
