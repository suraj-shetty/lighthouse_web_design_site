Layout

  • 375: full-height glass sheet: handle → header (filter icon, title, close; subtitle below) → divider → two panes: a rail of dimensions (Category, Brand; the active one carries a chevron, an inactive one with selections a dot) and the option rows (tick + label, "All" first) → RESET above APPLY.
  • 768 / 1440: side sheet with the same panes; RESET and APPLY side by side.
  • States: default (Category active, "All" ticked), selected (two categories and one brand → APPLY (3), dot on Brand), brand (Brand pane active), loading (skeleton lines in the right pane), empty ("No categories found" / "No brands found"), error (toast + the empty text).
  • Multi-select within a dimension; "All" clears it. RESET clears both without closing. APPLY stores the selection and reloads the products. Close discards the working selection.

Components used

  • Side / bottom sheet · IconButton glass (close)
  • Two-pane picker: vertical tabs + checkbox rows
  • Button stroke L (RESET) · Button filled L (APPLY / APPLY (n)) · Skeleton · Toast

Motion

  • Open / close: --panel-*
  • Dimension change: --tabs-*; option check, --select-check-*
  • Button press: --press-*

Accessibility

  • Dialog named "Filters". The rail is a vertical tab list controlling the option panel; options are checkboxes, with "All" as the clear-all control.
  • The dot on an inactive dimension has a text alternative ("has selections"). APPLY announces the selected count. Focus returns to the filter button.

Decisions to confirm

  • "Category" lists project types and sends them as the marketplace category filter (Q-66): sample names reflect that.
  • Only the first 50 brands load (Q-72). Brand empty text is "No brands found".
