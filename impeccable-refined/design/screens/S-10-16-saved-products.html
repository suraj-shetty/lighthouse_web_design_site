Layout

  • 375: as the app: back + title; one column of cards with a single image (no carousel), rating pill, filled save button, brand tag + SKU, title (2 lines), Reference Price.
  • 768: 2-column grid.
  • 1440: 4-column grid (3 at 1200 with the menu expanded); Refresh button replaces pull-to-refresh.
  • Next page: a small spinner row at the end. Empty and error are centred blocks; RETRY shows only when the list is empty.

Components used

  • Navigation shell · Top header (glass) with back · IconButton glass (refresh)
  • Product card (single image, rating pill, save pressed, brand tag, SKU, Reference Price)
  • Skeleton cards · Spinner · Empty state · Button filled S (RETRY) · Toast (danger)

Motion

  • Skeleton → content: --skel-*, --shimmer-*, --reveal-*; next page, --stagger-*
  • Un-save: --icon-swap-*, then the card leaves the grid; card press, --press-*
  • Back and card push: page transition; toast, --toast-*

Accessibility

  • h1 "Saved Products"; the cards are a list; each card is one link named by its title.
  • The save button is pressed and labelled "Remove from saved"; removal is announced in a live region (and by the toast on failure).
  • Empty and error blocks are headings with body text; RETRY is a button.

Decisions to confirm

  • Empty body copy is kept verbatim: "Saved products you like and they'll show up here."
  • Error glyph: the app uses Alert02, which is not approved; information-circle is used.
  • Un-saving removes the card at once and restores it in place if the request fails.
  • The error message is the server / repo text; "Network error occurred" is a sample.
