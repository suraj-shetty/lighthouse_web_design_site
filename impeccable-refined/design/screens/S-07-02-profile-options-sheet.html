Layout

  • 375: glass bottom sheet sized to its content: drag handle and a single row, above the home indicator.
  • 768 / 1440: menu anchored to the More button of the profile header.

Components used

  • Bottom sheet / popover menu
  • Menu row (icon + label)

Motion

  • Open / close: --panel-* (sheet slides up on mobile; the menu fades and scales from its trigger from 768)
  • Row press: --press-*. Block User closes this menu, then opens S-07-03.

Accessibility

  • Menu semantics named "Profile options" with one menu item.
  • Focus moves into the sheet; Esc, a scrim tap and (mobile) drag down close it and return focus to the More button.

Decisions to confirm

  • Glyph: Flutter uses UserBlock01, which is not in ICONS.md. UserRemove01 is used, matching Block User in the feed options menu (S-05-03).
  • No Report action on a profile, as in Flutter (Q-94).
