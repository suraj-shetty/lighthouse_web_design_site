Delivery Location

Choose a saved delivery location or add a new one.

Loading delivery locations

Layout

  • 375: draggable glass sheet (85% height): handle, title, subtitle, scrolling location cards (pin tile, label, sub-address, premise line, check when selected), then the "Add new delivery location" tile.
  • 768 / 1440: side sheet stacked over the Order Confirmation sheet.
  • States: default three saved locations, the current one checked · loading skeleton cards · empty only the add tile.
  • The third card shows the label fallback "Delivery Location".

Components used

  • Bottom sheet / side sheet · IconButton glass (close)
  • Select card (default / selected, with check)
  • Button translucent M with leading icon (add tile) · Skeleton

Motion

  • Open / close: --panel-* (bottom sheet under 768, side sheet from 768)
  • Button press: --press-*; toast, --toast-*
  • Card select: --select-check-*; skeleton, --skel-*, --shimmer-*

Accessibility

  • Dialog named by the title; locations are a radiogroup whose names include label and address; the checked state is exposed and shown with a check and a darker border.
  • The add tile is a button; focus returns to Select / Change on close.

Decisions to confirm

  • Choosing a location closes the picker and returns it to S-11-15.
  • "Add new delivery location" opens the Add / Edit Delivery Location sheet owned by F-14 (S-14-21).
  • Errors are not handled in this widget in the app (owned by the delivery-location controller); no error state is drawn.
  • Glyph: the pin uses Location01.
