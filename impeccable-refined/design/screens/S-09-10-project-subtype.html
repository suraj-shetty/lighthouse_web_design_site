Layout

  • 375: tall glass sheet: handle → title → subtitle → single-select rows → full-width ADD.
  • 768 / 1440: side sheet; the second step of the type pick, in the same place as S-09-09.
  • The title and subtitle carry the chosen type, lower-cased ("residential"). ADD commits type and sub-type together as two chips on the Project Type row.
  • States: default (nothing picked → ADD disabled), selected (reopened for the same type), type-changed (ADD also raises the "Spaces cleared" toast), empty ("No options found": the type cannot be committed). No loading: sub-types arrive with their type.

Components used

  • Side / bottom sheet · IconButton (back, close)
  • Radio rows · Button filled L (ADD) · Toast

Motion

  • Step change and close: --panel-*
  • Radio: --select-check-*; toast, --toast-*

Accessibility

  • Dialog labelled by its title; radio group; ADD exposes its disabled state.
  • A Back control returns to step 1 with the type still selected.

Decisions to confirm

  • Back and close buttons are web additions (the app has neither).
  • Sub-type names are sample data.
