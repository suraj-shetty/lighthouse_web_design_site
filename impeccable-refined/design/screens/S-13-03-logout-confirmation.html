Logout Confirmation

Are you sure you want to logout?

Logout

Layout

  • Centred dialog at every width (max 400): title, one line of body, two equal buttons side by side.
  • Tapping outside dismisses it, as in the app.
  • Opened from Logout in the My Account menu (S-13-02) and from the MORE card on Manage Account (S-13-05).

Components used

  • Modal / Dialog (confirm)
  • Button filled M ×2: both buttons use the same inverse fill, as in the app
  • Spinner (loading)

Motion

  • Open / close: --modal-*
  • Button press: --press-*
  • After logout the sign-in screen replaces everything with no transition (as the app).

Accessibility

  • alertdialog named by its title and described by its body; focus trapped; initial focus on Cancel; Esc = Cancel; focus restored on close.
  • While the session ends both buttons are disabled and Logout announces "Logging out".

Decisions to confirm

  • Loading state is a web addition: per Q-20 the website also ends the session on the server (POST v1/auth/logout), so Logout shows a spinner until it returns. The app has no spinner.
  • No error handling is defined for a failed server logout (not in the app).
  • Logout is not styled as destructive because the app uses the same fill for both buttons.
