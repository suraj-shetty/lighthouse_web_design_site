Remove space

Remove "Living Pavilion" from the project? This cannot be undone.Remove "this space" from the project? This cannot be undone.

Layout

  • Centred dialog at every width: title, one message, Cancel and Remove side by side.
  • Edit mode only, from the delete icon on an existing space. Not dismissible by tapping outside (as the app).
  • States: default (titled space) and untitled (the message reads "this space"). Loading, empty and error do not apply: no request is made here.
  • Remove only queues the removal; it is sent when UPDATE is pressed.

Components used

  • Modal / Dialog (destructive confirm)
  • Button filled M (Cancel) · Button destructive M (Remove)

Motion

  • Open / close: --modal-*
  • Button press: --press-*

Accessibility

  • alertdialog named by its title and described by its message; initial focus on Cancel; Esc = Cancel.
  • The destructive action is separated by colour and label. Focus returns to the space list.

Decisions to confirm

  • The copy says "cannot be undone", yet leaving the edit screen without UPDATE discards the pending removal (kept verbatim).
  • Remove is drawn as a destructive button; the app draws both buttons filled.
