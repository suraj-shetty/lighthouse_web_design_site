Layout

  • 375: full feed cards (the Home feed card, F-05) for the list the tapped tile belongs to: posts, projects, videos or tagged. Floating glass header with back and the centred title.
  • 768 / 1440: one centred feed column at reading width; cards are not stretched.
  • Role switch = whose posts these are, matching the profile categories of S-07-01.
  • Title is "@{userName}" of the profile owner; "Posts" when there is no username.
  • States: default, loading (spinner footer while the next page loads; there is no first-load skeleton because the grid already holds the list), empty ("No posts").

Components used

  • Top header · IconButton glass (back)
  • Feed card from Home feed: media frame, Like / Save, count buttons, avatar + verified badge
  • Spinner footer · single-line empty text

Motion

  • Open: jumps near the tapped post, then settles it just under the header (Flutter: 250 ms ease-in-out; --reveal-*).
  • Next page when within 700 px of the end: --stagger-*; back: --page-slide-*; card actions as on Home (--like-*, --icon-swap-*).

Accessibility

  • Banner with the title as h1; the list is a feed of articles, each titled by its author heading.
  • Back is labelled; the targeted post receives the scroll position and focus; "Loading more posts" is announced politely.

Decisions to confirm

  • Error: not handled in Flutter (a failed next page is silent), so no error state is drawn here.
  • Card copy, actions and their sheets belong to the Home feed (F-05).
