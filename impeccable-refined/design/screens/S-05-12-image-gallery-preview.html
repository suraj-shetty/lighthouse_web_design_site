Layout

  • 375: full screen: glass gradient header (round back button, title up to 2 lines, "n / N" pill when there is more than one image) over a horizontal pager of images; a row of dots centred near the bottom.
  • 768: large modal with the same header, visible previous / next buttons at the sides.
  • 1440: lightbox (up to 1120 × 820) with title, counter, close, previous / next, zoom toggle and dots below the image.
  • Swipe or use the arrows: every slide carries its own counter and dots. With one image the counter, dots and arrows are omitted.
  • Loading and error apply per image: spinner, or "Unable to load image preview" on that page only.

Components used

  • Top header (gradient glass)
  • IconButton glass: back, close, previous, next, zoom
  • Image gallery / Media viewer (image count badge, dots)
  • Spinner

Motion

  • Open / close: --page-slide-* under 768 · --mediaview-open-dur from 768
  • Pager: --tab-panel-*; dots, --tabs-*
  • Zoom: --resize-dur

Accessibility

  • The title is the dialog heading; the counter is announced on change as "n of N"; dots are decorative.
  • Previous / next / back / close are labelled; arrow keys page; Esc closes; focus returns to the opener.
  • Each image has its own alt text where the data provides one.

Decisions to confirm

  • Counter text is "{current} / {total}" with spaces here but "{current}/{total}" in the feed viewer: kept as in the app.
  • Dots were chosen over thumbnails on desktop to match the app.
  • Only remote image URLs reach this viewer; blank entries and PDFs are filtered out first.
