Layout

  • 375: the same frame as S-03-01: back + 3-segment progress (segment 2 current); title, subtitle; single-select list of roles (icon · name · radio) with hairlines; CONTINUE at the bottom.
  • 768: centred card.
  • 1440: wider card, the list flows in two columns; CONTINUE right-aligned.
  • States: default (none selected, CONTINUE disabled), selected, loading (skeleton rows, shown before the list appears), empty (no roles returned: empty list, disabled CONTINUE). There is no error state here: a failed load keeps the user on S-03-01 with a toast.

Components used

  • IconButton solid (back)
  • Progress (segmented bar)
  • Radio option rows with a leading icon
  • Button filled L (disabled / active)
  • Skeleton

Motion

  • Radio: --select-check-*; step change in either direction, --tab-panel-*; loading, --skel-*, --shimmer-*.

Accessibility

  • h1 = title. The list is a radiogroup, arrow-key navigable; icons are decorative.
  • Progress text alternative "Step 2 of 3". Back returns to S-03-01 with Professional still selected.

Decisions to confirm

  • Role names are sample data; the list comes from the Professionals category, sorted by its sort order.
  • Glyphs: Sofa01 (interior) and UserFullView (consultant) are not approved; Sofa03 and User are used.
  • Selected radio uses the shared Radio component (inverse fill); the spec names --accent.
  • The empty state has no message in the app.
