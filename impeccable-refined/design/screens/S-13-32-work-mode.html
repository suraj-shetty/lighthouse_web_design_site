Layout

  • 375: glass bottom sheet (up to 90% height): handle, title and subtitle, content, full-width button pinned above the safe area.
  • 768 / 1440: side sheet from the right over Manage Account, same content, button in the sheet footer.
  • Three rows (label, radio on the right, hairline between).
  • States: default saved mode preselected · empty nothing saved yet, "SAVE" disabled · error the sheet has already closed; the toast shows over Manage Account and the row keeps its old value.

Components used

  • Bottom sheet / side sheet · IconButton glass (close)
  • Radio option row
  • Button filled L (enabled / disabled) · Toast (danger)

Motion

  • Open / close: --panel-* (slides up under 768, slides in from the right from 768).
  • Select: --select-check-*; press, --press-*; toast, --toast-*.

Accessibility

  • Dialog named by the sheet title; focus moves into the sheet, is trapped, and returns to the row it was opened from; Esc and the scrim close it.
  • Radio group named "Work Mode"; the disabled state of SAVE is exposed.
  • The error toast is announced politely after the sheet closes.

Decisions to confirm

  • No loading state in the sheet: SAVE closes it and Manage Account saves behind the blocking loader (S-13-09).
  • The app draws square tick boxes for this single choice; here radios, so the control matches its behaviour.
  • Q-109: "Both" can be saved, but About shows only Remote / Hybrid.
  • The row exists only for Architects and Interior Designers.
