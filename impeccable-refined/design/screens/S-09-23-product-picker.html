Layout

  • 375: full screen: header (close · title · filter) → scrolling list of product rows (64 thumbnail, brand chip, title up to 2 lines, Price + amount) → glass pill search fixed at the bottom, above the keyboard.
  • 768: modal; search moves to the top under the header; list in 2 columns.
  • 1440: modal with search and filter at the top and a 3-column product grid.
  • Opened from Materials "Products" on the project form and from a tap on the image in S-09-22. Single select: tapping a product returns it and closes.
  • States: default (first page, 15 per page), more (spinner as the last item while the next page loads), loading (6 skeleton rows), empty ("No products found"), error (toast; the list is cleared so the empty text remains).

Components used

  • Full-screen / modal panel · IconButton glass (close, filter)
  • Search input · Product row (list / grid) · Tag (brand chip)
  • Skeleton rows · Spinner · Toast

Motion

  • Open / close: --page-slide-* under 768, --modal-* from 768
  • Results: --skel-* → --reveal-*; next page, --stagger-*
  • Filter sheet: --panel-*

Accessibility

  • Heading = title. Search labelled "Search products". Each product is a button named "<brand> <title>, price <amount>".
  • Loading, "No products found" and "Loading more products" are announced politely. Focus returns to the caller on close.

Decisions to confirm

  • The filter button shows no applied-state indicator, as in the app: consider a dot and count on web.
  • Search sits at the bottom only under 768 (app parity); DOM order keeps it before the list for keyboard users.
  • Prices and brands are sample data; cards do not link to the marketplace (Q-62).
