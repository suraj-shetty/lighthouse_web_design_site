Accessibility

  • h1 is the header title; each card is a labelled region with an h2; label / value pairs are description lists.
  • The button is named "Contact dealer"; while the call intent is created it is busy and announces "connecting".

  • Dealer identity stays hidden ("Authorized Dealer 1") on this screen.
