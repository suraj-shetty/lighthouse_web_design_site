Layout

  • 375: glass bottom sheet over the scrim: drag handle, title, subtitle, field label, multi-line text box, character counter right-aligned under it, "Update".
  • 768 / 1440: side sheet from the right over Manage Account (440 wide, no drag handle); same order, actions pinned to the bottom.
  • Role switch: brand = "About the Brand" / label "About"; reseller = "About the Business" / label "Bio". Every state is drawn for both.
  • unset shows the hint; limit shows the hard stop at 250/250.

Components used

  • Bottom sheet / side sheet
  • IconButton glass (close)
  • Textarea: default, focus, error, disabled, with counter
  • Button filled L (Update, with loading)
  • Toast danger

Motion

  • Open / close: --panel-*
  • Button press: --press-*
  • Error toast: --toast-*
  • Counter change: --text-swap-*

Accessibility

  • Dialog named by its title; focus moves into the sheet, is trapped, and returns to the Manage Account row that opened it; Esc or the scrim closes without saving.
  • While saving the primary button is disabled and announces its busy label; toasts are announced through a polite live region.
  • The counter is tied to the textarea with aria-describedby and is a polite live region (announce near the limit, not on every key).

Decisions to confirm

  • The app's tap-to-edit box is an ordinary textarea on web.
  • error shows "About the Brand cannot be empty" inline. The app never displays it, and uses the same string for resellers ("About the Business"): confirm both.
  • State server-error shows the sheet as it stays after a failed request, with the "Error" toast (server message, else "Network error occurred" / "Something went wrong. Please try again later."). No retry control, as the app.
