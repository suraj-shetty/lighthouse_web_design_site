Layout

  • 375: content-height bottom sheet that rises above the keyboard: handle, title, subtitle, six reason rows, a text box only when "Other" is chosen, full-width SUBMIT.
  • 768 / 1440: centred modal dialog with the same content and a close button.

Components used

  • Bottom sheet (under 768) / Modal dialog (from 768)
  • Radio rows (reasons) · Textarea
  • Button filled L (SUBMIT: disabled, enabled, loading) · Toast (success, danger)

Motion

  • Open / close: --panel-* under 768, --modal-* from 768
  • Reason select: --select-check-*; textarea reveal, --reveal-*
  • Toast: --toast-*

Accessibility

  • Dialog named "Report this Product". Reasons are a radio group (one at a time).
  • The textarea is labelled "Describe the issue" and required when "Other" is chosen.
  • SUBMIT exposes aria-disabled and aria-busy; the result is announced by the toast; focus returns to the "…" button.

Decisions to confirm

  • SUBMIT is enabled once a reason is chosen and, for "Other", once the text is not blank. In the mockup this works live: pick a reason in the default state.
  • Success closes the sheet and shows "Reported" / "Thanks for helping us keep the marketplace accurate." Failure keeps the sheet open with the selection and shows "Report" / {server message}.
  • While submitting, the reasons and the text box are locked.
  • The app draws the reasons with its multi-select row style; web uses radios because only one can be chosen.
