Layout

  • 375: mirrors the Flutter screen: glass header (avatar, logo, filter), three equal chips, single column, floating glass tab bar with the separate action button.
  • 768: floating glass menu, collapsed by default: logo mark on top, icons with a label tooltip on hover / focus, action button, profile at the foot. Tapping the logo mark expands it.
  • 1440: the same menu, expanded by default: full logo, labels, and a collapse button. The choice is remembered. Recommended over a top header: one pattern from tablet up, and the top stays free for each page's own glass bar.
  • The top bar has no background at rest. Once content scrolls under it, its glass fades in: a floating glass bar from 768, the app's gradient-fade blur on mobile (--duration-fast).
  • The menu keeps its expanded / collapsed state when you move between screens; only the logo mark and the collapse button change it.
  • Feed stays one centred column on every width (cards are not stretched). Refresh button replaces pull-to-refresh from 768.

Components used

  • Nav bar (glass pill, active disc, unread dot) · Sidebar / rail
  • Top header (gradient-fade glass) · IconButton glass / plain
  • Chip (default / selected) as a tablist
  • Avatar, avatar stack, verified badge
  • Media frame: image count, glass button M, carousel arrows (pointer only), seek bar, mute
  • Like / Save buttons, count buttons · Button text (more / less, Retry, Dismiss) · Button filled S (Clear Filters)
  • Banner + Progress bar · Skeleton · Empty state · Toast (danger) · Spinner

Motion

  • Press on every button and card target: --press-*
  • Menu tap (try Explore ⇄ Discover): the active pill stretches from the old item over the new one (--duration-quick, --ease-out) while the page fades and blurs out (--blur-large); it then contracts onto the new item (--tabs-*) while the new page rises in sharp, block by block (--stagger-*).
  • Menu expand / collapse: width --resize-*, labels fade --duration-quick
  • Chip selection: --tabs-*; feed swap, --tab-panel-*
  • Chip row hide on scroll down / show on scroll up (mobile only): Flutter 200 ms ease-in-out; --home-chips-* is empty (Q-26)
  • Like: --like-* on like only; Save and Mute, --icon-swap-*
  • Unread / filter dot: --badge-pop-*; Toast, --toast-*
  • Skeleton to content: --shimmer-*, --skel-*, --reveal-*; carousel height, --resize-*
  • Sheets opened from here (filters, options, comments, likes, people): --panel-*; media viewer, --mediaview-open-dur

Accessibility

  • Landmarks: nav "Primary", header, main as a feed of articles; each card title is an h2.
  • Chips are a tablist; nav uses aria-current; Notifications label says "unread" (not colour alone).
  • Icon buttons are labelled: Profile, Filters (+ "filters active"), Refresh, More options, Like, Comments, Share, Save, Mute, Next image, Create / More actions.
  • Every target is at least 44 × 44 (small visuals carry a larger hit area). Focus ring is --focus-ring.
  • Toast and upload banner are polite live regions; reduced motion collapses all durations.
  • Videos autoplay muted and need a pause control in build; carousel has arrow buttons for pointer and keyboard.

Decisions to confirm

  • Glass follows the Flutter widgets (fill, 1px gradient hairline top to bottom, blur, inner shine), using the tokens. Where the app hard-codes a value the tokens differ from (dark fill #505050 → black at 60%, nav blur 7), the token is used.
  • EXPLORE PROJECT mirrors the app: 85% of the card width (capped at 360 on wide screens), 48 high, label + arrow.
  • Collapse button uses ArrowLeft01; ICONS.md has no sidebar glyph.
  • Profile entry moves from the header avatar to the menu foot from 768 (header avatar kept on mobile).
  • Nav labels "Home, Explore, Discover, Marketplace, Notifications, Create, More actions" are web additions (Q-48).
  • Glyphs: spec names Notification01, Menu01 and UserSwitch, which are not in ICONS.md. Used Notification03 and MoreHorizontal from the approved list.
  • Error state = error toast + the app's empty placeholder (Q-06); Refresh retries.
  • Filled button follows the live design system (--bg-inverse), not --element-bg-button-linear-* named in DESIGN_SPEC §8.
  • Liked / saved fill the same Hugeicons stroke-rounded outline (Favourite, Bookmark02) with --like-color / --save-color.
  • Hashtags use --text-link and stay inert (Q-33, Q-52). Image alt text is sample copy (Q-36).
