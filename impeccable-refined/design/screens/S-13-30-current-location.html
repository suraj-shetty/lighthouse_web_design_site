Layout

  • 375: glass bottom sheet (up to 90% height): handle, title and subtitle, content, full-width button pinned above the safe area.
  • 768 / 1440: side sheet from the right over Manage Account, same content, button in the sheet footer.
  • Search input (auto-focused, with clear button); below it either the search results, the empty prompt, or the "SELECTED LOCATION" block with one tile (name, sub-address, remove).
  • States: default saved location · results suggestions for "Kora" (they replace the selected block) · loading skeleton rows while searching · no-results · empty nothing selected, no query · validation SAVE with nothing selected → toast "Please select a city" · saving · error toast, sheet stays open.

Components used

  • Bottom sheet / side sheet · IconButton glass (close)
  • Search input with clear IconButton
  • Result list rows · Skeleton
  • Location tile with remove IconButton · Empty state
  • Button filled L, with loading · Toast (danger)

Motion

  • Open / close: --panel-* (slides up under 768, slides in from the right from 768).
  • Suggestions: --stagger-*; pick, --select-check-*; remove, --icon-swap-*.
  • Press: --press-*; toast, --toast-*.

Accessibility

  • Dialog named by the sheet title; focus moves into the sheet, is trapped, and returns to the row it was opened from; Esc and the scrim close it.
  • Search is a combobox with a results listbox; "No results found" is announced.
  • Each selected tile has a remove button named "Remove <place>"; list changes are announced politely.
  • While saving, search and remove are disabled and the button announces "Saving".
