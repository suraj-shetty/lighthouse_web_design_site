Unfollow

Layout

  • 375: glass bottom sheet: drag handle, identity block (full name, @username), two rows with a hairline between them.
  • 768 / 1440: menu anchored to the FOLLOWING button (or the collapsed following icon).
  • Identity falls back to "User" and "@username".

Components used

  • Bottom sheet / popover menu
  • Menu row (icon + label)

Motion

  • Open / close: --panel-*; row press: --press-*
  • Unfollow closes the menu and the profile returns to FOLLOW with followers −1 (optimistic).

Accessibility

  • Menu labelled by the identity block; rows are menu items.
  • Esc, a scrim tap and (mobile) drag down close it; focus returns to the follow button.

Decisions to confirm

  • Mute Notifications only closes the sheet, as in Flutter (Q-91: ship inert, hide, or implement?).
  • Glyph: Flutter uses NotificationBlock01, which is not in ICONS.md. VolumeOff is used as the closest "mute" glyph.
  • An unfollow failure reverts on the profile with the toast "Error" + server message (shown on S-07-01).
