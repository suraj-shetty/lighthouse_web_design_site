Layout

  • 375: content-height glass bottom sheet: handle, headline, the "Recommended" card (ribbon, Lighthouse mark + title, description, three check chips, filled CTA) and the second card (title, description, outlined CTA).
  • 768 / 1440: side sheet from the right, 440 wide, same stack; the footer stays pinned.
  • One state only: both cards always show; there is no data fetch. An empty dealer list is handled in S-11-14.

Components used

  • Bottom sheet / side sheet · IconButton glass (close)
  • Option card · Label "Recommended" · Tag with check (static)
  • Button filled L · Button translucent L

Motion

  • Open / close: --panel-* (bottom sheet under 768, side sheet from 768)
  • Button press: --press-*; toast, --toast-*
  • Each CTA closes this sheet and opens the next one (S-11-15 or S-11-14): --panel-*

Accessibility

  • Dialog named by the headline; each card is a group with a heading.
  • "Recommended" is text, not colour alone; the chips are a plain list, not controls.
  • Focus order: GET BEST PRICE, then SELECT DEALER; focus returns to the product CTA on close.

Decisions to confirm

  • Cards stay stacked in the side sheet at 1440 (the spec allows side by side in a modal).
  • The caller (product detail, F-10) blocks opening until every variant group is selected.
  • The ribbon text uses the default text colour on the recommended tint for contrast; the star carries the recommended colour.
