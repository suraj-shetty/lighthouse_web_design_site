Library

Browse and access your saved media and collections.

Layout

  • 375: glass bottom sheet sized to content: handle, title, subtitle, divider, four rows (icon · label · tick or chevron).
  • 768 / 1440: popover anchored to the filter label.
  • States show which filter is current; with an album chosen no row carries a tick and "All Album" keeps its chevron.

Components used

  • Bottom sheet / popover
  • Menu row as a radio (single-select)

Motion

  • Open / close: --panel-*
  • Row press: --press-*; "All Album" opens S-09-03 on top, --panel-*

Accessibility

  • Dialog named "Library"; rows form a radio group; the current row is conveyed by aria-checked and the tick, not colour alone.
  • Esc, scrim tap and drag down close without change; focus returns to the filter label.

Decisions to confirm

  • No entry point on web. Q-08 replaces the device library with a file picker, so there is nothing to filter. Designed for parity with the app; confirm it is dropped.
