Layout

  • 375: glass bottom sheet (up to 90% height): handle, title and subtitle, content, full-width button pinned above the safe area.
  • 768 / 1440: side sheet from the right over Manage Account, same content, button in the sheet footer.
  • List of rows: name, description below it, tick box on the right, hairline between rows.
  • States: default saved preferences ticked · loading saving · empty "No collaboration preferences found." (also shown when the options fail to load) · error toast, sheet stays open.

Components used

  • Bottom sheet / side sheet · IconButton glass (close)
  • Checkbox option row with description
  • Button filled L, with loading · Toast (danger)

Motion

  • Open / close: --panel-* (slides up under 768, slides in from the right from 768).
  • Tick: --select-check-*; press, --press-*; toast, --toast-*.

Accessibility

  • Dialog named by the sheet title; focus moves into the sheet, is trapped, and returns to the row it was opened from; Esc and the scrim close it.
  • Checkbox group; each description is linked to its option with aria-describedby.
  • While saving, rows are disabled and the button announces "Saving".

Decisions to confirm

  • Title and subtitle come from the API category (name and description); the fallbacks are shown here.
  • Option names and descriptions are sample data.
  • The options load before the sheet opens, behind the blocking loader (S-13-09).
  • In the empty state "DONE" just closes the sheet.
