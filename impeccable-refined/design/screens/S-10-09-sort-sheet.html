Layout

  • 375: bottom sheet at half the screen height: handle, title, subtitle, options with hairlines; the current option is bold with a tick on the right.
  • 768 / 1440: dropdown popover under the sort button.
  • No loading or empty state: the sheet does not open until the option list has at least one value.

Components used

  • Bottom sheet / popover
  • Single-select option row (radio semantics, tick)

Motion

  • Open / close: --panel-*
  • Tick: --select-check-*; row press, --press-*

Accessibility

  • Dialog named "Sort"; options form a radio group; the checked state is exposed (tick and weight are not the only signals).
  • Arrow keys move between options; Enter selects and closes; focus returns to the sort button.

Decisions to confirm

  • Options are the dev backend values (2026-11-12): latest-first, oldest-first, top-rated, price-low-to-high, price-high-to-low, shown with separators replaced by spaces and every word capitalised (so "Price Low To High"). The list is server data.
  • Default is "Latest First". Picking an option closes the sheet and refetches with the current filters.
