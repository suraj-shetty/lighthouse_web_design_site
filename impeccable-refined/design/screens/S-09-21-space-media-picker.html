Layout

  • Web adaptation (Q-08): the device gallery becomes a file picker / drop zone; the camera tile becomes the add tile.
  • 375: tall glass sheet: handle → header row (title + subtitle left, ADD pill right) → 3-column square grid whose first cell is the add tile, then the added media with numbered selection badges and video durations.
  • 768 / 1440: side sheet with a compact drop zone above the thumbnail grid.
  • States: default (the space's current media preselected → ADD (3)), empty (only the add tile / drop zone, ADD disabled), loading (15 skeleton cells while files are read and compressed), drag-over, limit (10 selected; further picks are refused).
  • ADD returns the selection, which replaces the space's media. The 10-per-space cap is separate from the project carousel's cap.

Components used

  • Side / bottom sheet · Button filled S (ADD / ADD (n))
  • File drop zone (compact) · add tile
  • Selectable grid tile (order number, duration) · Skeleton · Toast

Motion

  • Open / close: --panel-*
  • Tile select: --select-check-*; new tiles, --stagger-*
  • Skeleton: --skel-* / --shimmer-*

Accessibility

  • Dialog named "Gallery". Tiles are toggle buttons named with media type, duration and selected position.
  • The selection count is announced politely; reaching 10 is announced (silent in the app).
  • ADD announces its count. Esc / scrim close without change; focus returns to the Add button on S-09-20.
