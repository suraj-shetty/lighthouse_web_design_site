Layout

  • Third tab of a brand or dealer profile (S-07-01). The file shows the panel in the same profile frame as the other tabs: cover, summary and tab row, with the panel beside the summary from 1200.
  • Brand: "Browse By Category" in the same image-and-label strip as applications (5 tiles + a "View All" tile when there are more than 6, else all), then "Browse By Application" strip with "View All". Dealer: "Browse By Brand" strip (at most 5 + a "View All" tile), then "Browse By Category" in the same strip; no applications.
  • 375: 3-column category grid, horizontal image strips, space below for the Contact bar.
  • 768: category grid gains columns; strips stay horizontally scrollable.
  • 1440: strips wrap into a grid row, so nothing needs a horizontal scroll with a pointer.

Components used

  • Section header (title + "View All" / "Showing {shown}/{total}")
  • Select card tiles (category, outlined "View All") · Style card tiles (brand, application)
  • Skeleton · single-line empty text · Footer CTA bar · Tabs

Motion

  • Tiles: --press-*; sections enter with --stagger-*; skeleton: --shimmer-*, --skel-*, --reveal-*
  • Category / brand / application tiles push the product list (--page-slide-*); the category "View All" tile opens All categories with a fade (--panel-*).

Accessibility

  • Tab panel labelled "Shop"; each section is a region with an h2.
  • Tiles are links named by the brand, category or application; a category with subcategories is a button that opens the subcategory picker first.
  • Strips are focusable groups, so they scroll with the keyboard; "View All" links say what they list.

Decisions to confirm

  • Error: not handled in Flutter (a failed section is simply left out). When everything fails the tab shows "No shop items yet.".
  • Tile images have empty alt text because the label under each tile names it (Q-36).
  • The "View All" tiles use GridView and ArrowRight01; label fallbacks are "Brand", "Category", "Application".
  • Destinations belong to Marketplace: product list S-10-07, subcategory picker S-10-04, All categories S-10-03, Applications S-10-05, Brands S-10-06.
  • Contact stays as a floating button at every width on this file, because the summary card that holds it on desktop is on S-07-01.
