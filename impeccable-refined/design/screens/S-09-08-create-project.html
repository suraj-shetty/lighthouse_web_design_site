Layout

  • One scrolling form with sections: not a wizard.
  • 375: glass header (close · title). Media carousel (COVER badge on the first image, remove chip) → cover hint → title → description → people card → BASIC INFO → PROJECT STORY → MATERIALS & PRODUCTS → CREDITS. Sticky full-width SHARE / UPDATE above the tab bar.
  • 768: one centred column, cards at content width.
  • 1440: two columns: media (3-up grid), title and description on the left and sticky; section cards on the right; primary button right-aligned in a sticky footer bar. Pickers open as side sheets or popovers.
  • States: default (create, filled), empty (blank → SHARE disabled), invalid (SHARE pressed with required rows missing), edit, edit-empty (only "+" → UPDATE disabled), loading, error (toast).
  • Picked values show as chips under their row; an option named "Other" reveals a free-text field on the form (max 120).

Components used

  • Top header · IconButton glass (close)
  • Carousel tile · Tag dark (COVER) · IconButton glass on media (remove, move, play)
  • Textarea (title, description) · Card with tap-to-edit rows · Tag (value chip) · removable chip · inline text field
  • Button filled S (Add, Add Chapter) · IconButton (delete) · helper error text
  • Sticky CTA bar · Button filled L (disabled, loading) · Toast

Motion

  • Pickers: --panel-*; dialogs and loader, --modal-*
  • Tile lift / button press: --press-* (no reorder recipe, Q-71)
  • Toasts: --toast-*; push / pop, --page-slide-* (desktop --panel-*)

Accessibility

  • Heading = title; each section eyebrow is a level-2 heading and its card a group.
  • Title and description are labelled "Title" / "Description" and required; required rows read ", required".
  • Picker rows are buttons announcing label and value. Chips have named remove buttons.
  • Keyboard reorder: "Move earlier" / "Move later" on every tile; the alt text of the first image announces "cover".
  • Validation messages are role="alert" under their row and focus moves to the first invalid row.
