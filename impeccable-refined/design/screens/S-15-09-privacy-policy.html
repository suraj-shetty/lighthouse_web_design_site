Layout

  • 375: mirrors the app: centred title with back, then the embedded web page filling the rest of the screen with rounded top corners.
  • 768 / 1440: the frame sits in a reading-width column (760) inside the app shell, with all four corners rounded.
  • The frame loads https://lighthouseinfra.com/privacy-policy/. The policy text is not in the app, so the mockup shows the frame, its address and neutral lines in place of the remote content.
  • Reached from "Privacy Policy" in Manage Account → MORE, and from the privacy link on Sign in (signed-out: same page without the menu).

Accessibility

  • The frame carries the title "Privacy Policy", the same as the h1; links inside it stay keyboard reachable.
  • Back is labelled "Back"; the fallback message is announced; the fallback button is a real link to the public page.
  • While loading the region is marked busy.
