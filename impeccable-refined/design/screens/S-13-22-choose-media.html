Choose Media

Layout

  • 375: small glass bottom sheet: title and two full-width glass buttons with icons.
  • 768: popover anchored to "Browse file".
  • 1440: not shown: "Browse file" opens one system file chooser that accepts images and PDF.
  • Single state; there is nothing to load and a cancelled pick changes nothing.

Components used

  • Bottom sheet / popover
  • Button glass L ×2 with leading icon

Motion

  • Open / close: --panel-* (sheet under 768, fades and scales from its trigger from 768).
  • Button press: --press-*.

Accessibility

  • Dialog named "Choose Media"; both options are buttons.
  • On web the file input states the accepted types (JPEG, PNG, PDF) in its label.
  • Esc and the scrim close it; focus returns to "Browse file".

Decisions to confirm

  • In this mockup "Select Image" goes straight to S-13-23 and "Select File" to S-13-24; in the product the system picker and (for images) the crop step S-13-07 come in between.
  • Duplicate attachments are ignored silently, as the app.
  • Glyphs: Image02 and File02 (the app uses the same pair).
