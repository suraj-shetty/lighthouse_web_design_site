Layout

  • 375: tall glass sheet over the Library sheet: handle, title, subtitle, 2-column grid of album tiles (cover, name, item count).
  • 768 / 1440: side sheet; grid in 3 columns.
  • Only non-empty albums are listed. Picking one closes this sheet and the Library sheet.

Components used

  • Bottom sheet / side sheet · IconButton glass (close)
  • Album tile (cover + two text lines) · Skeleton (4 tiles) · Empty text

Motion

  • Open / close: --panel-*
  • Skeleton: --skel-* / --shimmer-*; tile press, --press-*

Accessibility

  • Dialog named "All Albums"; each tile is a button named "<album>, <count> items"; covers are decorative.
  • Esc / scrim return to the Library sheet; focus is trapped while open.
