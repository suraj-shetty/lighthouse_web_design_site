Layout

  • 375: glass back button + title, search field, then collapsible sections: header row (icon, uppercase title, chevron) and, when open, a card of labelled switches divided by hairlines. "Notification Channels" is first and open; one section per backend category follows, collapsed.
  • 768: the same in a centred column.
  • 1440: settings layout in two columns: channels pinned on the left, category sections on the right.
  • States: default, search (query "review": only matching items, matching sections forced open), push-blocked (browser permission not granted), loading, empty ("No matching settings found"), error (message + Retry).
  • Channel labels, category titles and item labels come from the backend; the ones here are sample data. Channels the backend marks unavailable are not listed.

Components used

  • Top header · IconButton glass (back) · Search input (with clear)
  • Accordion (section header + card) · Switch (on, off, locked) · Settings rows
  • Info banner (push blocked) · Skeleton · single-line empty text · Button text (Retry) · Toast (failed toggle: "Error" + message)

Motion

  • Section expand / collapse: --panel-*; switch: --duration-fast; skeleton: --shimmer-*, --skel-*; toast: --toast-*; back: --page-slide-*

Accessibility

  • h1 is the title; each section header is a disclosure button with an h2 and its expanded state.
  • Every switch has role="switch" and its label; a locked switch is aria-disabled, shows a lock, and says "Always on. This setting cannot be changed.".
  • Search is labelled; the number of matches is announced politely; the error has a focusable Retry; toasts use aria-live.

Decisions to confirm

  • Browser push (Q-23, in scope): turning Push on asks for the browser notification permission through OneSignal web push first. If it is not granted the switch stays off. Flutter has no copy for that case; the banner text in state push-blocked is a web addition to approve. The backend push-subscription endpoint still needs a web platform value.
  • The Push switch shows on only when the backend preference is on and this browser is subscribed; the browser state is re-read when the tab regains focus.
  • Search placeholder is "Search...", the default of the shared Flutter search field.
  • Locked switches show a lock and an "always on" explanation for assistive technology; Flutter only dims them.
  • Category glyphs: CheckmarkBadge02 → CheckmarkCircle01, Activity03 → Pulse01, Folder01 → FolderOpen (not in ICONS.md); Settings02, Invoice01 and Notification03 as in Flutter.
  • Navigation highlight: the screen is pushed from My profile, which has no tab of its own; Home is used as the parent tab.
